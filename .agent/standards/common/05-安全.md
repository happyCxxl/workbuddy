# 05 · 安全

> 跨语言安全底线。语言细节与框架配置见各语言目录。
> 编号 `COMMON-SEC-xx`。

## 1. 密钥与凭据

（COMMON-SEC-01）密钥只允许来自环境变量或本地未入库配置文件；禁止硬编码、禁止提交、禁止写进日志。

（COMMON-SEC-02）密钥与内网地址禁止进入 AI 提示词；提交前自查 diff 中是否出现 `secret`、`password`、`token`、内网 IP。

## 2. 鉴权

（COMMON-SEC-03）鉴权只认服务端判断；前端的路由守卫、按钮显隐只是体验，不作为权限依据。

（COMMON-SEC-04）每个对外接口都要有明确的访问级别：公开、登录可用、管理员。默认拒绝。

## 3. 输入与输出

（COMMON-SEC-05）所有外部输入在边界校验：类型、长度、取值范围、枚举合法性。校验只写一次，写在入口。

（COMMON-SEC-06）SQL 只允许参数化绑定或 ORM，禁止拼接；动态排序字段必须走白名单。

（COMMON-SEC-07）对外返回的数据只含页面需要的字段；实体、内部状态、密钥类字段不得直接外泄。

## 4. 文件

（COMMON-SEC-08）上传文件必须校验：扩展名白名单、大小上限、内容类型；存储路径由服务端生成，禁止用客户端文件名拼路径。

（COMMON-SEC-09）下载接口按身份校验归属，禁止仅凭可猜测的 ID 放行。

## 5. 依赖

（COMMON-SEC-10）不引入已知高危漏洞版本的依赖；新增依赖须在交付说明写明版本与用途。

## 6. 日志

（COMMON-SEC-11）日志不打印密码、令牌、完整手机号/身份证号、密钥；定位需要时打印 ID。

（COMMON-SEC-12）异常日志不把堆栈或内部标识直接返回给客户端；对外只给错误码与可读提示。
