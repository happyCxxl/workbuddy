# 02 · 组件与样式

> 编号见 `00-规则索引.md` §6.4–§6.5；本文只写条款正文与正反例。

## 1. 组件

（WEB-COMP-001）组件名始终多个单词（根组件除外），如 `TodoItem`。

（WEB-COMP-002）prop 定义含：camelCase 命名、类型、`required`/`default` 二选一、用途注释；枚举取值加 `validator`。

（WEB-COMP-003）`v-for` 必须配 `key`，用稳定业务 ID，不用数组下标。

（WEB-COMP-004）`v-if` 与 `v-for` 不得出现在同一元素：过滤场景抽计算属性，显隐场景把 `v-if` 移到容器。

（WEB-COMP-005）组件样式必须隔离：本项目统一用 `scoped` 属性，全局样式只允许进 `styles/`。Vue 指南同属 A 级，但它也接受 CSS Modules 与 BEM，本项目不采用，避免三套并存。

【应该】单文件组件顶级顺序统一为 `<template>` → `<script>` → `<style>`。Vue 指南把这条列为 C 级推荐（`script` 与 `template` 两种顺序都合法），本项目固定其中一种以保证全库一致，由 `check-spec` 统一校验。

（WEB-COMP-007）组件文件用 PascalCase；模板中使用时也用 PascalCase 且自闭合。Vue 指南只要求文件名风格全库一致（PascalCase 或 kebab-case 皆可），本项目固定 PascalCase。

（WEB-COMP-008）基础组件用 `Base` 前缀（`BaseButton.vue`）；与父组件紧密耦合的子组件以父组件名作前缀（`TodoList` → `TodoListItem.vue`）。

（WEB-COMP-009）模板只放简单表达式，复杂逻辑进计算属性或方法。

（WEB-COMP-010）指令一律用缩写（`:`、`@`、`#`）。

正例：prop 带类型、默认值与说明。

```ts
const props = withDefaults(defineProps<{
  /** 列表项标题 */
  title: string
  /** 是否可展开，缺省不可展开 */
  expandable?: boolean
}>(), { expandable: false })
```

反例：prop 只有类型，没有默认值也没有 `required`。

```ts
const props = defineProps<{ expandable?: boolean }>()   // 调用方不传时得到 undefined
```

【应该】`v-if` 与 `v-show`：频繁切换用 `v-show`，运行期条件基本不变用 `v-if`。【应该】attribute 较多时一行一个，顺序为 `class`/`id` → 绑定属性 → 事件。

## 2. 样式

（WEB-CSS-001）样式嵌套不超过 3 层。

（WEB-CSS-002）设计变量（色板、间距、字号、圆角）统一维护在 `styles/` 变量文件；页面与组件内禁硬编码颜色值，个别业务色除外。

（WEB-CSS-003）列表表格走全局骨架类：表体滚动层用 `page-table-body`、`el-table` 挂 `page-table`、`#empty` 插槽用 `page-table-empty`。三处样式只在 `styles/page-shell.css` 的「列表表格」一节定义，页面内不得再抄一份。

（WEB-CSS-004）同一张表的每一列写同一个 `min-width` 数值字面量，不写 `width`。Element Plus 按各列 `min-width` 的比例分配富余宽度，同值即等宽；写死 `width` 的列退出该分配，写百分比会让分配算出 `NaN`。

（WEB-CSS-005）列统一写 `align="center"`；需要左对齐的列不写 `align`。

正例：三列等宽、居中。

```vue
<el-table class="page-table" :data="rows">
  <el-table-column prop="name" min-width="160" align="center" />
  <el-table-column prop="status" min-width="160" align="center" />
</el-table>
```

反例：混用 `width` 与百分比，列宽失控。

```vue
<el-table-column prop="name" width="160" />
<el-table-column prop="status" width="30%" />
```

【应该】选择器尽量用直接子选择器（`>`）而非后代选择器。
