# 03 · 路由、异步与工程化

> 编号见 `00-规则索引.md` §6.5。

## 1. 路由与状态

（WEB-ROUTE-001）路由一律懒加载：`component: () => import('@/views/...')`。

（WEB-ROUTE-002）path 用 kebab-case 且以 `/` 开头；name 与页面组件名一致（PascalCase）。

（WEB-ROUTE-003）页面间传参用路由 query / params，禁止借全局状态传参（刷新即丢）。

（WEB-ROUTE-004）全局状态用 Pinia，只放跨页面共享数据（登录态等）；页面私有状态留在页面内。

（WEB-ROUTE-005）store 变更一律经 actions，页面内禁止直接改 store 数据。

## 2. 异步与错误处理

（WEB-ASYNC-001）异步统一 `async/await`，业务代码不用 then 链。

（WEB-ASYNC-002）请求层统一拦截：响应 `code !== 0` 统一提示 `msg` 并拒绝；`40101` 统一跳登录；`40500` 统一兜底提示。页面只处理成功分支，`catch {}` 留空是正常写法。

（WEB-ASYNC-003）页面数据展示必须有加载中、空数据、异常三态，不得裸渲染。

（WEB-ASYNC-004）用户可见的写操作（提交、删除、发布）必须带二次确认与结果提示。

【应该】组件卸载时取消未完成的请求与轮询，避免内存泄漏与竞态。

## 3. 工程化

（WEB-ENG-001）ESLint 与 Prettier 全库统一配置，禁止个人改写规则绕过检查；确需放宽，先改规范再改配置。

（WEB-ENG-002）门禁两段：pre-commit 只做就地修复（lint-staged 结果回写索引）；pre-push 全量校验（`pnpm lint` 八步）。手动预检用 `pnpm lint`。

（WEB-ENG-003）提交信息沿用 Conventional Commits，scope 用 `web`：`feat(web)`、`fix(web)`、`docs(web)`、`refactor(web)`。

（WEB-ENG-004）Node 与 pnpm 版本在 `package.json` 钉住。

（WEB-ENG-005）构建产物、`node_modules`、编辑器与系统文件进 `.gitignore`。

（WEB-ENG-006）新增依赖最小化：能用现有依赖解决的禁止引新库；引新库须在交付说明写明理由。

## 4. 检查引擎与交付

`pnpm lint` 八步：格式、eslint、vue-tsc、stylelint、ls-lint、API 词表、规范合规（check-spec）、表格口径（check-table）。口径为 0 错误。

| 检查类别                       | 引擎                                     | 触发     |
|--------------------------------|------------------------------------------|----------|
| 类型错误                       | vue-tsc --noEmit                         | pre-push |
| 未使用代码、恒真条件           | eslint no-unused-vars / no-unnecessary-* | pre-push |
| 样式合法性                     | stylelint                                | pre-push |
| 代码格式                       | prettier                                 | pre-push |
| 文件命名与 API 词表            | ls-lint / check-naming                   | pre-push |
| SFC 结构、`scoped`、路由懒加载 | check-spec                               | pre-push |
| 表格骨架类、等宽列、居中       | check-table                              | pre-push |

机器覆盖不到的条款（三态、二次确认、契约对齐、注释质量）按 `delivery-checklist.md` 逐条自查，交付说明附结论。

已知盲区：`vue-tsc` 不解析指令名，`v-loadin` 这类拼写错误由 eslint `vue/no-undef-directives` 兜住；运行时全局注册的指令要同时登记 `src/env.d.ts` 的 `GlobalDirectives` 与 `eslint.config.mjs` 的 `ignore`。
