# 前端交付自查清单

> 用途：机器门禁覆盖不了的规范条款，在每次代码交付前逐项自查，并在交付说明中给出逐项结论。

## 评审层条款

- [ ] 注释只写"做什么"，不写谁写的/为什么/从哪来/阶段（规范 §9.1）
- [ ] 页面数据展示具备加载中 / 空数据 / 异常三态（规范 §8.3，接入接口后生效）
- [ ] 用户可见的写操作带二次确认与结果提示（规范 §8.4）
- [ ] 接口字段与后端 Controller 源码对齐，Long 类型 ID 一律按字符串处理（规范 §2.3）
- [ ] 时间字段经 `utils/` 时间工具统一格式化（规范 §2.3.6）
- [ ] 全局状态只放跨页面共享数据，store 变更一律经 actions（规范 §7.4 / §7.5）
- [ ] 组件卸载时取消未完成的请求与轮询（规范 §8.5）
- [ ] 类名/组件名反映语义，无拼音与随意缩写（规范 §3.3 / §6.1）

## 机器层条款（无需人工核对）

以下条款已由钩子门禁自动拦截（就地修复在 pre-commit，全量校验在 pre-push）：格式（prettier）、代码规范与命名/嵌套（eslint）、类型（vue-tsc）、样式（stylelint）、文件命名（ls-lint）、API 词表（check-naming）、SFC 结构与未使用类名（check-spec）、列表表格口径（check-table：骨架类 / 等宽列 / 居中）。
