# 03 · 命名与类职责

> 本文件只写规则，与具体模块、具体类名无关。

## 1. 大小写

（JAVA-NAME-008）类名 `UpperCamelCase`；方法、参数、字段、局部变量 `lowerCamelCase`；常量全大写下划线分隔；包名全小写、单数。

依据：阿里手册命名风格第 3–5、9 条；Google Java Style §5.2。

## 2. 角色与后缀

（JAVA-NAME-001）后缀与角色绑定：出现在下表「强制位置」的类，必须以对应后缀结尾；「强制位置」为空的后缀可选，用则必须承担表中职责，不用不算违规。领域概念、枚举、值对象、算法与框架组件不在这张表内，用领域名词命名，不要求后缀。

位置与包的对应见 `02-包结构.md`。

| 后缀            | 强制位置         | 是什么                                                    | 允许依赖             |
|-----------------|------------------|-----------------------------------------------------------|----------------------|
| `Controller`    | 入口层           | HTTP 入口：绑定参数、调用用例、包装响应                   | 用例接口             |
| `Service`       | 用例接口         | 用例接口，一个用例一个方法                                | —                    |
| `ServiceImpl`   | 用例实现         | 用例实现，编排与事务边界                                  | 数据访问、助手、算法 |
| `DbService`     | 单表数据访问门面 | 单表数据访问门面，CRUD 与查询组装，不含业务判断           | 映射接口             |
| `DbServiceImpl` | 数据访问实现     | 数据访问实现，继承持久化基类                              | 映射接口             |
| `Mapper`        | 映射接口         | 映射接口，只声明 SQL                                      | 实体                 |
| `DTO`           | 请求契约         | 请求入参（后缀全大写）                                    | 无                   |
| `VO`            | 响应契约         | 响应出参（后缀全大写）                                    | 无                   |
| `Converter`     | 转换层           | 数据载体之间的单向字段转换（入参↔实体↔出参）              | 数据载体             |
| `Support`       | —                | 无状态辅助：统计、解析、守卫                              | 数据访问、其它助手   |
| `Helper`        | —                | 纯函数集合                                                | 无                   |
| `Handler`       | —                | 框架回调：异常出口、拒绝处理、降级                        | 视场景               |
| `Provider`      | —                | 可替换的能力实现，多实现按配置选择                        | 底层客户端           |
| `Registry`      | —                | 注册表或查找表，启动期装载、运行期只读                    | 无                   |
| `Resolver`      | —                | 从多来源解析出单个结果                                    | 数据访问、助手       |
| `Runner`        | —                | 任务执行器，一个任务类型一个                              | 数据访问、算法       |
| `Config`        | —                | 框架配置类；映射基线用 `*ConvertConfig`（非 Spring 配置） | 无                   |
| `Properties`    | —                | 配置绑定对象                                              | 无                   |
| `Util`          | —                | 静态工具，`final` + 私有构造 + 全静态                     | 无                   |
| `Exception`     | —                | 业务异常类型                                              | 无                   |
| `Enum`          | —                | 码值枚举，带解析方法                                      | 无                   |
| `Strategy`      | —                | 可替换的算法实现，同族共用一个接口                        | 无框架依赖           |
| `Context`       | —                | 一次执行中的可变上下文                                    | 可持有实体与中间结果 |
| `Result`        | —                | 单步或单算法的产出                                        | 不查库、不含行为     |
| `Info`          | —                | 实体或产出的附属信息片段                                  | 无                   |
| `Processor`     | —                | 后置处理步骤，对已有结果再加工                            | 输入输出同族         |
| `Record`        | —                | 一次运行或一次冲突的记录行                                | 视场景               |
| `Snapshot`      | —                | 某一时刻的只读快照                                        | 无                   |
| `Factory`       | —                | 按条件创建实例                                            | 底层客户端           |
| `Builder`       | —                | 把多段输入拼装成整体对象                                  | 不查库               |
| `Listener`      | —                | 事件监听器，只做转发                                      | 用例接口             |
| `Client`        | —                | 外部服务客户端，只做协议转换                              | 底层 SDK             |
| `Consumer`      | —                | 队列消费者                                                | 用例接口、任务执行器 |
| `Query`         | —                | 领域检索请求对象                                          | 无                   |
| `Param`         | —                | 算法入参的成组对象                                        | 无                   |

依据：Google Java Style §5.2.2 只要求类名 `UpperCamelCase`，不设后缀强制；阿里手册命名风格把后缀强制挂在具体角色上——POJO 用 DO/DTO/VO（第 3、16 条）、抽象类 `Abstract`/`Base` 开头与异常类 `Exception` 结尾（第 6 条）、Service 与 DAO 实现类用 `Impl`（第 14 条），未设「全体类名后缀白名单」；Spring 按组件类型命名（`*Controller`、`*Service`、`*Repository`、`*Configuration`、`*Properties`）。角色位置到后缀的映射为本项目决定。

## 3. 命名细则

（JAVA-NAME-002）契约层后缀统一：请求契约 `Xxx<动作>DTO`、响应契约 `XxxVO`，后缀全大写。契约包内不得使用 `Request`、`Response`、`View`、`Filter` 作后缀。

契约包之外的类不受本条约束：框架过滤器、领域请求体这类角色不是契约，用它们自己的语义命名。

（JAVA-NAME-003）`XxxServiceImpl` 必须实现同名 `XxxService`，一对一。

（JAVA-NAME-004）数据访问接口一表一个，命名体现表名。

（JAVA-NAME-005）技术助手的后缀限定所在层：纯函数助手只在算法层，编排层用 `Support`。

其它规则：

- 抽象类以 `Abstract` 或 `Base` 开头；异常类以 `Exception` 结尾；含测试方法的类以 `Test` 结尾（见 `06-测试.md`）。
- 枚举建议带 `Enum` 后缀，成员全大写。
- 禁止拼音与英文混用、禁止中文命名、禁止下划线或美元符号开头结尾。
- 禁止不规范缩写，使用完整单词。

依据：阿里手册命名风格第 2、6、10、15、16 条。

## 4. 类职责边界

（JAVA-NAME-006）`Handler` 只用于框架回调，不做业务编排。

（JAVA-NAME-007）工具类 `final`、私有构造、全静态，不持有可变状态。

（JAVA-NAME-009）未使用的私有方法、私有字段、形参、局部变量必须删除，不留「备用」。

依据：Google Java Style §6.1——不产生副作用的未使用代码属于死代码；阿里 OOP 规约要求及时清理不再使用的类与方法。

| 类型        | 可以做                   | 不可以做                 |
|-------------|--------------------------|--------------------------|
| Controller  | 绑定、调用用例、包装响应 | 查库、拼装出参、判断权限 |
| ServiceImpl | 编排、事务边界           | 直接依赖映射接口         |
| DbService   | 单表 CRUD 与查询组装     | 业务判断、跨表编排       |
| Assembler   | 字段搬运                 | 查库、判断               |
| Support     | 无状态辅助               | 开启事务                 |
