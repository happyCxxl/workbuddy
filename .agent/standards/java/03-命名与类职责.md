# 03 · 命名与类职责

> 本文件只写规则，与具体模块、具体类名无关。

## 1. 大小写

（JAVA-NAME-008）类名 `UpperCamelCase`；方法、参数、字段、局部变量 `lowerCamelCase`；常量全大写下划线分隔；包名全小写、单数。

依据：阿里手册命名风格第 3–5、9 条；Google Java Style §5.2。

## 2. 后缀词表

（JAVA-NAME-001）类名后缀只能取自下表；表外后缀不得新增，需要新增时先登记并写清职责边界。

| 后缀            | 是什么                                          | 允许依赖             |
|-----------------|-------------------------------------------------|----------------------|
| `Controller`    | HTTP 入口：绑定参数、调用用例、包装响应         | 用例接口             |
| `Service`       | 用例接口，一个用例一个方法                      | —                    |
| `ServiceImpl`   | 用例实现，编排与事务边界                        | 数据访问、助手、算法 |
| `DbService`     | 单表数据访问门面，CRUD 与查询组装，不含业务判断 | 映射接口             |
| `DbServiceImpl` | 数据访问实现，继承持久化基类                    | 映射接口             |
| `Mapper`        | 映射接口，只声明 SQL                            | 实体                 |
| `DTO`           | 请求入参（后缀全大写）                          | 无                   |
| `VO`            | 响应出参（后缀全大写）                          | 无                   |
| `Assembler`     | 实体到出参的纯映射                              | 无                   |
| `Support`       | 无状态辅助：统计、解析、守卫                    | 数据访问、其它助手   |
| `Helper`        | 纯函数集合                                      | 无                   |
| `Handler`       | 框架回调：异常出口、拒绝处理、降级              | 视场景               |
| `Provider`      | 可替换的能力实现，多实现按配置选择              | 底层客户端           |
| `Registry`      | 注册表或查找表，启动期装载、运行期只读          | 无                   |
| `Resolver`      | 从多来源解析出单个结果                          | 数据访问、助手       |
| `Runner`        | 任务执行器，一个任务类型一个                    | 数据访问、算法       |
| `Config`        | 框架配置类                                      | 无                   |
| `Properties`    | 配置绑定对象                                    | 无                   |
| `Util`          | 静态工具，`final` + 私有构造 + 全静态           | 无                   |
| `Exception`     | 业务异常类型                                    | 无                   |
| `Enum`          | 码值枚举，带解析方法                            | 无                   |
| `Strategy`      | 可替换的算法实现，同族共用一个接口              | 无框架依赖           |
| `Context`       | 一次执行中的可变上下文                          | 可持有实体与中间结果 |
| `Result`        | 单步或单算法的产出                              | 不查库、不含行为     |
| `Info`          | 实体或产出的附属信息片段                        | 无                   |
| `Processor`     | 后置处理步骤，对已有结果再加工                  | 输入输出同族         |
| `Record`        | 一次运行或一次冲突的记录行                      | 视场景               |
| `Snapshot`      | 某一时刻的只读快照                              | 无                   |
| `Factory`       | 按条件创建实例                                  | 底层客户端           |
| `Builder`       | 把多段输入拼装成整体对象                        | 不查库               |
| `Listener`      | 事件监听器，只做转发                            | 用例接口             |
| `Client`        | 外部服务客户端，只做协议转换                    | 底层 SDK             |
| `Consumer`      | 队列消费者                                      | 用例接口、任务执行器 |
| `Query`         | 领域检索请求对象                                | 无                   |
| `Param`         | 算法入参的成组对象                              | 无                   |

来源分层：`DTO`、`VO`、`Impl`、`Exception`、`Abstract`/`Base` 开头取自阿里手册命名风格（强制条款）；其余为本项目决定的角色后缀，依据是职责边界。

## 3. 命名细则

（JAVA-NAME-002）请求对象 `Xxx<动作>DTO`、响应对象 `XxxVO`；不使用 `Request`、`Response`、`View`、`Filter` 作后缀。

（JAVA-NAME-003）`XxxServiceImpl` 必须实现同名 `XxxService`，一对一。

（JAVA-NAME-004）数据访问接口一表一个，命名体现表名。

（JAVA-NAME-005）技术助手的后缀限定所在层：纯函数助手只在算法层，编排层用 `Support`。

其它规则：

- 抽象类以 `Abstract` 或 `Base` 开头；异常类以 `Exception` 结尾；测试类以 `Test` 结尾。
- 枚举建议带 `Enum` 后缀，成员全大写。
- 禁止拼音与英文混用、禁止中文命名、禁止下划线或美元符号开头结尾。
- 禁止不规范缩写，使用完整单词。

依据：阿里手册命名风格第 2、6、10、15 条。

## 4. 类职责边界

（JAVA-NAME-006）`Handler` 只用于框架回调，不做业务编排。

（JAVA-NAME-007）工具类 `final`、私有构造、全静态，不持有可变状态。

| 类型        | 可以做                   | 不可以做                 |
|-------------|--------------------------|--------------------------|
| Controller  | 绑定、调用用例、包装响应 | 查库、拼装出参、判断权限 |
| ServiceImpl | 编排、事务边界           | 直接依赖映射接口         |
| DbService   | 单表 CRUD 与查询组装     | 业务判断、跨表编排       |
| Assembler   | 字段搬运                 | 查库、判断               |
| Support     | 无状态辅助               | 开启事务                 |
