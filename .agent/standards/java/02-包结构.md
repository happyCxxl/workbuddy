# 02 · 包结构

> 各模块的包职责清单（JAVA-LAYER-004）。新增包先在此登记，再建目录。
> 模块依赖白名单见 `01-分层与依赖.md` §1。

## 1. `workbuddy-biz`

| 包                    | 职责                                            | 允许依赖                  |
|-----------------------|-------------------------------------------------|---------------------------|
| `biz/controller/<域>` | HTTP 入口：参数绑定、调 Service、包 `R`         | `biz/service`             |
| `biz/service`         | 应用服务接口：一个用例一个方法                  | —                         |
| `biz/service/impl`    | 应用服务实现：编排、事务边界                    | `db`、`worker`、`support` |
| `biz/service/db`      | 单表数据访问接口：CRUD 与查询组装，不含业务判断 | —                         |
| `biz/service/db/impl` | 数据访问实现，继承 `InfraDbService`             | `mapper`                  |
| `biz/service/support` | 无状态辅助：VO 组装、统计、策略解析             | `db`、其它 `support`      |
| `biz/mapper`          | MyBatis-Plus 映射接口，只声明 SQL               | 实体                      |
| `biz/task/runner`     | 环节任务执行器，一个环节一个                    | `db`、`worker`、`support` |
| `biz/task/support`    | 任务编排共用助手                                | `db`、`support`           |
| `biz/config`          | Spring 配置、全局异常出口、公共字段填充         | 全部                      |
| `biz/listener`        | 消息监听                                        | `service`、`task`         |
| `biz/startup`         | 启动校验项与链驱动                              | `service`                 |

## 2. `workbuddy-worker`

按环节分包（`parser`、`structure`、`preprocessing`、`chunking`、`embedding`、`indexing`、`retrieval`、`input`），每包内部分三层：

| 层        | 职责                             |
|-----------|----------------------------------|
| 根包      | 环节对外契约：策略接口、结果对象 |
| `impl`    | 具体算法实现，按子类目再分包     |
| `support` | 算法内部共用助手                 |

## 3. `workbuddy-common`

| 包                         | 职责                                      |
|----------------------------|-------------------------------------------|
| `common/dto/request/<域>`  | 请求对象                                  |
| `common/dto/response/<域>` | 响应对象与 `R`                            |
| `common/domain/entity`     | 表实体，一表一类                          |
| `common/domain/input`      | 跨层输入对象                              |
| `common/domain/rules`      | 领域规则常量与判定                        |
| `common/enums`             | 码值枚举                                  |
| `common/error`             | 错误码登记表                              |
| `common/exception`         | 业务异常与守卫工具                        |
| `common/annotation`        | 注解契约（`@AdminOnly`、`@RateLimit` 等） |
| `common/utils`             | 静态工具                                  |

## 4. `workbuddy-auth`

| 包             | 职责                                         |
|----------------|----------------------------------------------|
| `auth/config`  | Spring Security 配置、JWT 过滤器、拒绝处理器 |
| `auth/db`      | 用户表数据访问接口                           |
| `auth/mapper`  | MyBatis 映射                                 |
| `auth/service` | 用户与鉴权服务，事务边界                     |
| `auth/startup` | 启动校验项                                   |
| `auth/util`    | 本模块工具（令牌签发与解析）                 |

## 5. `workbuddy-file`（包根 `filecenter`）

| 包                    | 职责                                 |
|-----------------------|--------------------------------------|
| `filecenter/config`   | 存储配置与属性绑定                   |
| `filecenter/db`       | 文件记录数据访问                     |
| `filecenter/mapper`   | MyBatis 映射                         |
| `filecenter/provider` | 存储提供者实现（本地 / MinIO）与路由 |
| `filecenter/service`  | 文件上传、下载、删除                 |
| `filecenter/startup`  | 存储探活等启动校验                   |

## 6. `workbuddy-infra`

| 包                  | 职责                        |
|---------------------|-----------------------------|
| `infra/config`      | 基础设施配置                |
| `infra/persistence` | 持久化基类 `InfraDbService` |
| `infra/ratelimit`   | 限流切面与令牌桶            |
| `infra/redis`       | Redis 封装与队列            |

## 7. `workbuddy-model`

| 包               | 职责                       |
|------------------|----------------------------|
| `model/config`   | 模型配置绑定（厂商、密钥） |
| `model/gateway`  | 模型调用网关               |
| `model/registry` | 模型内存注册表             |
| `model/startup`  | 启动装载与校验             |

## 8. `workbuddy-vector`

当前无子包：Milvus 客户端与集合操作直接放在 `com.workbuddy.vector` 下。新增类仍放根包；确需拆子包时先在本节登记，再建目录。
