# 02 · 组件与样式

> 本文件只写规则，与具体组件库、具体类名无关。

## 1. 组件

（VUE-COMP-001）组件名始终多个单词（根组件除外）。

（VUE-COMP-002）prop 定义必须包含：小驼峰命名、类型、`required` 或 `default` 二选一，以及用途注释；枚举取值加校验。

（VUE-COMP-003）循环必须配稳定业务 `key`，不用数组下标。

（VUE-COMP-004）条件与循环不得出现在同一元素：过滤场景抽计算属性，显隐场景把条件移到容器。

（VUE-COMP-005）组件样式必须隔离，全库只用一种方案（作用域样式、CSS Modules 或 BEM 三者选一），避免并存。

（VUE-COMP-006）单文件组件的顶层块顺序固定为 `<template>` → `<script>` → `<style>`。

（VUE-COMP-007）组件文件与模板引用统一一种大小写风格，并自闭合。

（VUE-COMP-008）基础组件加统一前缀；与父组件紧耦合的子组件以父组件名为前缀。

（VUE-COMP-009）模板只放简单表达式，复杂逻辑进计算属性或方法。

（VUE-COMP-010）指令一律用缩写。

【应该】频繁切换用显隐指令，运行期条件基本不变用条件指令。【应该】属性较多时一行一个，顺序为标识 → 绑定 → 事件。

依据：Vue 官方风格指南 Priority A / B。

## 2. 样式

（VUE-CSS-001）样式嵌套不超过 3 层。

（VUE-CSS-002）设计变量（色板、间距、字号、圆角）统一维护在一处；页面与组件内禁硬编码颜色，个别业务色除外。

（VUE-CSS-003）列表表格走统一骨架类，骨架样式只在一处定义，页面内不得再抄一份。

（VUE-CSS-004）同一张表的每一列写同一个 `min-width` 数值字面量，不写 `width`、不写百分比——写死宽度会退出框架的等宽分配，百分比会让分配失效。

（VUE-CSS-005）列统一居中；需要左对齐的列不写居中对齐。

（VUE-CSS-006）组件作用域样式禁用 `:deep`；需要定制子组件样式时，把覆盖写进全局样式文件。

（VUE-CSS-007）模板与脚本中未使用的样式类必须删除。

（VUE-CSS-008）`font-family` 必须写字体栈字面量并以通用字体族结尾，禁止 `var()` 形式。

（VUE-CSS-009）样式数值不得使用小数 px。

正例：三列等宽、居中。

```vue
<DataTable class="table-skeleton" :data="rows">
  <TableColumn prop="name" min-width="160" align="center" />
  <TableColumn prop="status" min-width="160" align="center" />
</DataTable>
```

反例：混用固定宽度与百分比，列宽失控。

```vue
<TableColumn prop="name" width="160" />
<TableColumn prop="status" width="30%" />
```

【应该】选择器尽量用直接子选择器而非后代选择器。
