# 00 · 前端规则索引

> 本文件只写规则体系自身的约束，与具体项目、具体目录无关；规则正文在 `01`–`03`。
> 本文不复述各条规则——索引复述正文必然漂移（此前 59 条规则在本文与正文各存一份）。

## 1. 分级

| 等级     | 含义           | 违反后果                       |
|----------|----------------|--------------------------------|
| 【必须】 | 可判定的底线   | 不合规，能机器化的一律机器拦截 |
| 【应该】 | 多数场景更优   | 偏离须在交付说明写明理由       |
| 【可以】 | 同等选项的默认 | 全库一致即可                   |

## 2. 编号

`VUE-<域>-<三位序号>`。只给【必须】条款编号；【应该】【可以】写在正文里不带编号。编号不复用，规则删除后序号作废。

| 域      | 覆盖                             |
|---------|----------------------------------|
| MACHINE | 由工具 100% 强制的格式与文件命名 |
| LANG    | 通用语言约定（对齐 Google TS）   |
| DIR     | 目录与文件组织                   |
| API     | 接口层                           |
| NAME    | 命名                             |
| STYLE   | 代码风格（机器覆盖不到的）       |
| DOC     | 注释                             |
| COMP    | 组件                             |
| CSS     | 样式与表格                       |
| ROUTE   | 路由与状态                       |
| ASYNC   | 异步与错误处理                   |
| ENG     | 工程化与门禁                     |

## 3. 执行者

| 判定值     | 含义                             |
|------------|----------------------------------|
| `工具`     | 格式化器与 lint 规则，构建期执行 |
| `类型检查` | 类型检查器，构建期执行           |
| `形态检查` | 命名、结构、表格口径的约定扫描   |
| `静态分析` | 跨语言的注释与文档检查           |
| `评审`     | 交付前按评审清单逐条核对         |
| `变更门禁` | 推送或合并时执行                 |

## 6. 评审项（上限 5 条）

> 评审项指下面清单的条目数，不是规则条数；判定为「评审」的规则必须挂在其中一个条目下。

交付说明里给出逐项结论，未核对的按未交付处理：

- [ ] **目录与接口**：页面与组件目录符合规则；HTTP 调用只在接口层；请求与响应以后端契约为单一事实源、超安全整数 ID 按字符串、分页字段固定、时间统一经时间工具格式化；请求层统一实例与拦截；path kebab-case 且 name 与组件名一致、页面传参用路由参数、全局状态只放跨页面数据且变更经 actions；路由守卫与菜单可见性同源；组件文件与模板引用的大小写一致并自闭合（DIR-001/002、API-001/003/004/005/006/007/008/009、ROUTE-002/003/004/005/006/007/008、COMP-007）
- [ ] **组件契约**：prop 有类型与默认值、循环有稳定 key、条件与循环不混用；基础组件与紧耦合子组件前缀合规、模板只放简单表达式；命名禁拼音混拼、布尔/集合/回调带前缀；方法取词全库统一；注释只写契约（COMP-002/003/004/008/009、NAME-002/003/004、DOC-001/002）
- [ ] **异步与确认**：异步统一 async/await、页面只处理成功分支；数据展示有加载、空、异常三态；写操作有确认与提示（ASYNC-001/002/003/004）
- [ ] **样式收口**：设计变量不硬编码；表格骨架与列宽符合规则（CSS-002/003/004/005）
- [ ] **工程门禁**：lint 与格式化全绿；提交信息 Conventional Commits、运行时与包管理器版本钉住、忽略清单、新增接口前缀同步代理；新增依赖写明理由（ENG-001/003/004/005/006/007）
