# 00 · 前端规则索引

> 本文件只写规则，与具体项目、具体目录无关；规则正文在 `01`–`04`。

## 1. 分级

| 等级     | 含义           | 违反后果                       |
|----------|----------------|--------------------------------|
| 【必须】 | 可判定的底线   | 不合规，能机器化的一律机器拦截 |
| 【应该】 | 多数场景更优   | 偏离须在交付说明写明理由       |
| 【可以】 | 同等选项的默认 | 全库一致即可                   |

## 2. 编号

`VUE-<域>-<三位序号>`。只给【必须】条款编号；【应该】【可以】写在正文里不带编号。编号不复用，规则删除后序号作废。

| 域      | 覆盖                             |
|---------|----------------------------------|
| MACHINE | 由工具 100% 强制的格式与文件命名 |
| LANG    | 通用语言约定（对齐 Google TS）   |
| DIR     | 目录与文件组织                   |
| API     | 接口层                           |
| NAME    | 命名                             |
| STYLE   | 代码风格（机器覆盖不到的）       |
| DOC     | 注释                             |
| COMP    | 组件                             |
| CSS     | 样式与表格                       |
| ROUTE   | 路由与状态                       |
| ASYNC   | 异步与错误处理                   |
| ENG     | 工程化与门禁                     |

## 3. 执行者

| 判定值     | 含义                             |
|------------|----------------------------------|
| `工具`     | 格式化器与 lint 规则，构建期执行 |
| `类型检查` | 类型检查器，构建期执行           |
| `形态检查` | 命名、结构、表格口径的约定扫描   |
| `静态分析` | 跨语言的注释与文档检查           |
| `评审`     | 交付前按评审清单逐条核对         |
| `变更门禁` | 推送或合并时执行                 |

## 4. 依据

| 记号       | 含义                                                          |
|------------|---------------------------------------------------------------|
| `Vue-A`    | 外部出处：Vue 官方风格指南 Priority A（Essential）            |
| `Vue-B`    | 外部出处：Vue 官方风格指南 Priority B（Strongly Recommended） |
| `Google`   | 外部出处：Google TypeScript Style Guide                       |
| `工具默认` | 外部出处：格式化与 lint 工具的既有规则，本项目直接采纳        |
| 空白       | 本项目决策：无外部出处，理由写在条款正文                      |

## 6. 评审项（上限 5 条）

> 评审项指下面清单的条目数，不是规则条数；判定为「评审」的规则必须挂在其中一个条目下。

交付说明里给出逐项结论，未核对的按未交付处理：

- [ ] **目录与接口**：页面与组件目录符合规则；HTTP 调用只在接口层；请求层统一实例与拦截；路由守卫与菜单可见性同源；组件文件与模板引用的大小写一致并自闭合（DIR-001/002、API-001/004/008/009、ROUTE-006/007/008、COMP-007）
- [ ] **组件契约**：prop 有类型与默认值、循环有稳定 key、条件与循环不混用；方法取词全库统一；注释只写契约（COMP-002/003/004、NAME-002、DOC-001/002）
- [ ] **三态与确认**：数据展示有加载、空、异常三态；写操作有确认与提示（ASYNC-003/004）
- [ ] **样式收口**：设计变量不硬编码；表格骨架与列宽符合规则（CSS-002/003/004/005）
- [ ] **工程门禁**：lint 与格式化全绿；新增依赖写明理由（ENG-001/006）
