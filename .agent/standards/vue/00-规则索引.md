# 前端规则索引（knowledge-web）

> 本目录是 `web/` 的实现规范正典，分四份：`00` 索引、`01` 工程与命名、`02` 组件与样式、`03` 异步与测试。
> 后端规范在 `.agent/standards/java/`；接口契约以后端 Controller 源码为准。

## 1. 分级

| 等级     | 含义           | 违反后果                       |
|----------|----------------|--------------------------------|
| 【必须】 | 可判定的底线   | 不合规，能机器化的一律机器拦截 |
| 【应该】 | 多数场景更优   | 偏离须在交付说明写明理由       |
| 【可以】 | 同等选项的默认 | 全库一致即可                   |

## 2. 编号

`WEB-<域>-<三位序号>`。只给【必须】条款编号；【应该】【可以】写在正文里不带编号。编号不复用，退役后保留空位。

| 域      | 覆盖                             | 条数 |
|---------|----------------------------------|------|
| MACHINE | 由工具 100% 强制的格式与文件命名 | 1    |
| LANG    | 通用语言约定（对齐 Google TS）   | 1    |
| DIR     | 目录与文件组织                   | 2    |
| API     | 接口层                           | 7    |
| NAME    | JS/TS 命名                       | 5    |
| STYLE   | 代码风格（机器覆盖不到的）       | 1    |
| DOC     | 注释                             | 2    |
| COMP    | 组件                             | 9    |
| CSS     | 样式与表格                       | 5    |
| ROUTE   | 路由与状态                       | 5    |
| ASYNC   | 异步与错误处理                   | 4    |
| ENG     | 工程化与门禁                     | 6    |

## 3. 执行者

`pnpm lint` 八步（prettier / eslint / stylelint / ls-lint / vue-tsc / check-naming / check-spec / check-table）、`评审`（`delivery-checklist.md` 逐条核对）、`pre-push`（`.agent/tools/pre-push-gate.sh`）。

## 4. 状态

生效 / 试用 / 待落地 / 退役，含义同 Java 侧 `00-总则与规则索引.md` §4。

## 5. 来源

| 记号     | 含义                                                            |
|----------|-----------------------------------------------------------------|
| `Vue-A`  | Vue 官方风格指南 Priority A（Essential）                        |
| `Vue-B`  | Vue 官方风格指南 Priority B（Strongly Recommended）             |

## 7. 退役与拆分

- `WEB-NAME-006`（`this` 暂存用 `self`）退役：`<script setup>` 中无 `this`，且无出处。
- `WEB-COMP-006`（SFC 顶层顺序）退役编号，降为【应该】：Vue 指南列为 C 级，两种顺序均合法。
- 拆分理由与调研来源见 `../../README.md` §1 与本文 §5 的来源表。
