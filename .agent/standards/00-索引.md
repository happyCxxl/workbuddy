# 00 · 规范索引

> 规范的唯一入口。按「语言 × 主题」定位，AI 按任务路径按需加载，不读全文。
> 规则前缀按语言划分；跨语言共用的条款在 `common/`，语言专属的在各自目录。

## 1. 语言与目录

| 层     | 目录      | 规则前缀  | 适用对象                              |
|--------|-----------|-----------|---------------------------------------|
| 通用   | `common/` | `COMMON-` | 所有语言                              |
| Java   | `java/`   | `JAVA-`   | 后端多模块                            |
| Vue    | `vue/`    | `VUE-`    | 前端单页应用                          |
| 新语言 | `<语言>/` | `<LANG>-` | 接入规则见 `common/01-项目前提.md` §5 |

## 2. 按任务加载

| 我要改什么 | 先读                                               | 再读                       |
|------------|----------------------------------------------------|----------------------------|
| 任何代码   | `common/02-交付行为约束.md`、`common/03-反模式.md` | 对应语言目录               |
| Java 后端  | `java/00-总则与规则索引.md`                        | `java/01`–`java/08` 按主题 |
| 前端       | `vue/00-规则索引.md`                               | `vue/01`–`vue/04`          |
| 写规范本身 | `README.md`                                        | 本文件                     |

## 3. 规则索引的位置

| 层   | 索引                        |
|------|-----------------------------|
| 通用 | `common/` 各篇正文内的编号  |
| Java | `java/00-总则与规则索引.md` |
| Vue  | `vue/00-规则索引.md`        |

各语言的规则条数以对应索引为准，本文不维护数字。

## 5. 执行手段

| 手段                                           | 覆盖                                                   | 接入点                 |
|------------------------------------------------|--------------------------------------------------------|------------------------|
| Checkstyle / PMD / SpotBugs / CPD              | Java 风格、静态缺陷、重复代码                          | `mvn verify`、pre-push |
| JaCoCo                                         | Java 覆盖率（全库语句 ≥70%）                           | `mvn verify`、pre-push |
| `.agent/tools/common/check-modules.mjs`        | 模块结构：目录存在、无环、无自依赖                     | pre-push               |
| `.agent/tools/java/check-java-conventions.mjs` | Java 形态：后缀、命名、Javadoc、import、事务位置、行数 | pre-push               |
| `.agent/tools/java/check-javadoc.mjs`          | Javadoc 覆盖与形态：标记、摘要、标签、行尾注释、TODO   | pre-push、CI           |
| `.agent/tools/java/check-test-quality.mjs`     | 用例质量：恒真断言、无断言、只验交互、缺来源说明       | pre-push（改动文件）   |
| `.agent/tools/common/check-artifacts.mjs`      | 版本库未混入中间产物                                   | pre-push、CI           |
| PIT 变异检查（`-Pmutation`）                   | 核心模块用例可证伪性：存活变异逐条评估                 | 按需执行               |
| `.agent/tools/common/check-docs.mjs`           | 文档结构与小节禁项；文档引用路径有效                   | pre-push、CI           |
| `.agent/tools/common/check-encoding.mjs`       | 文件编码未损坏                                         | pre-push               |
| `.agent/tools/common/check-agents.mjs`         | 入口文件指针有效                                       | pre-push、CI           |
| `.agent/tools/common/pre-push-gate.sh`         | 按改动范围编排上述步骤                                 | pre-push               |
| `.agent/tools/java/verify.mjs`                 | Java 侧验证档位编排：检查器、定向用例、模块、全量      | 开发期按档执行         |
| `pnpm lint` 八步                               | Vue 格式、类型、命名、SFC、表格                        | pre-push               |
| 评审清单                                       | 机器判不了的条款                                       | 交付说明               |

## 6. 版本

本规范按提交版本迭代：**每一次提交即一次版本更新**。规则的增删改与代码变更同一次提交，版本历史以 `git log` 为准，不另设版本号。
