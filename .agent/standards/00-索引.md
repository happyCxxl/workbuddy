# 00 · 规范索引

> 规范的唯一入口。按「语言 × 主题」定位，按需加载，不读全文。
> 规则前缀按语言划分：跨语言条款在 `common/`，语言专属条款在各自目录。目录前缀与规则条数由各目录自己维护，本文不复述。
> 本目录要能被别的项目整包复用：正文只引用 `.agent/` 内的路径（由 `check-scope` 判定）。

## 1. 语言与目录

| 层     | 目录      | 规则前缀  | 适用对象                              |
|--------|-----------|-----------|---------------------------------------|
| 通用   | `common/` | `COMMON-` | 所有语言                              |
| Java   | `java/`   | `JAVA-`   | 后端多模块                            |
| Vue    | `vue/`    | `VUE-`    | 前端单页应用                          |
| 新语言 | `<语言>/` | `<LANG>-` | 接入规则见 `common/01-项目前提.md` §5 |

编号格式：`JAVA-<域>-<三位序号>`、`VUE-<域>-<三位序号>`（各语言目录 §2 维护）；`COMMON-<域>-xx` 沿用两位数，历史编号不改。
