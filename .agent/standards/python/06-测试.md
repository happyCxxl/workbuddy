# 06 · 测试

> 本文件写测试结构与确定性；规模、替身、覆盖率口径以 `../common/04-测试策略.md` 为准，这里只写 Python 落地。

## 1. 结构

（PY-TEST-001）pytest；测试文件与函数均以 `test_` 为前缀；`tests/` 目录镜像源码结构。判定：形态检查（工具）。

## 2. 确定性

（PY-TEST-002）测试以随机顺序运行（pytest-randomly）；不依赖执行顺序、真实时间、网络与真实中间件；时间与随机数用可控替身。

依据：`../common/04-测试策略.md` 的确定性口径；Shopify 用 pytest-randomly 消除测试顺序依赖。

（PY-TEST-003）替身只替换系统边界（外部 HTTP、对象存储、向量库、模型调用）；不得把被测逻辑的核心依赖 mock 掉、只留一串 `verify`。

依据：`../common/04-测试策略.md` §4/§8——mock 滥用是脆性测试的主要来源。

（PY-TEST-004）LLM 与模型调用一律 fake：测试内禁止真实模型调用；fake 能注入固定剧本与失败场景。

## 3. 覆盖率

（PY-TEST-005）覆盖率口径与门槛沿用 `../common/04-测试策略.md` §5：分母收敛到可执行行为，全库 ≥70%、核心链路 ≥90%、关键分支 100%。判定：覆盖率工具。

## 4. 规模与运行

（PY-TEST-006）按规模分档运行：small 不启动中间件；medium 只连 `localhost`（本地库）；large 只留核心旅程。异步测试用 pytest-asyncio。判定：测试运行配置。

依据：`../common/04-测试策略.md` §1——规模按运行所需资源分，不按代码行数分。
