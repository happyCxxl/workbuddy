# 04 · 数据访问

> 本文件写会话、迁移、事务、向量与库归属；与具体表名无关。通用安全口径见 `../common/05-安全.md`。

## 1. 会话与访问

（PY-DATA-001）SQLAlchemy 2.0 异步用法：`AsyncSession` 与异步引擎；引擎进程级单例；每请求一个 Session，请求结束回收。禁止同步引擎与异步引擎混用。

依据：SQLAlchemy 官方文档——混用同步/异步驱动导致隐式 IO 阻塞。

（PY-DATA-002）数据访问经 repository 类：类封装 Session，只含查询与写入方法，不含业务规则；查询参数走白名单与参数绑定，禁止拼接 SQL。判定：评审。

## 2. 迁移

（PY-DATA-003）schema 变更一律经 Alembic 迁移：迁移必须可回滚、可重复执行；禁止应用启动时自动建表；迁移脚本与模型改动同一次提交。

依据：本项目决策（与 java 域 DDL 口径一致）。

（PY-DATA-004）迁移只改结构不搬业务数据；数据订正走独立脚本并留痕。等级【应该】。

## 3. 事务

（PY-DATA-005）写操作在显式事务内完成；只读查询不开启事务；事务内禁止外部调用（模型、HTTP、慢 IO）。

依据：与 java 域事务口径一致——长事务持锁，外部调用时长不可控。

（PY-DATA-006）事务边界在用例层控制，repository 只执行不决定边界。

## 4. 向量

（PY-DATA-007）向量列与元数据同表同事务写入；检索距离与排序口径集中一处实现，禁止散落；禁止全表向量扫描。

## 5. 库归属

（PY-DATA-008）每服务只访问自己的库；跨服务数据经 API 或事件获取，禁止共享库、跨库 join、直连他方库。

依据：`../common/01-项目前提.md` 的功能域契约约束——共享库会重新制造双写与耦合。
