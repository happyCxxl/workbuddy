# 07 · AI 服务

> AI 域特有约束：模型出口、循环契约、结构化输出、用量、prompt 安全、工具审批、评测与记忆。与语言规则并列，只适用于 AI 服务。

| 小节          | 判定     | 具体怎么判                             |
|---------------|----------|----------------------------------------|
| 1 模型出口    | 形态检查 | 供应商 SDK 导入白名单（后续 AST 扫描） |
| 2 循环契约    | 评审     | 状态转移场景清单逐条核对               |
| 3 结构化输出  | 测试     | Pydantic 校验与重试上限由单测固定      |
| 4 用量        | 评审     | 调用明细字段齐全                       |
| 5 prompt 安全 | 评审     | 密钥与注入边界                         |
| 6 工具与审批  | 评审     | 注册表与审批留痕                       |
| 7 评测        | 变更门禁 | 评测集运行通过                         |
| 8 记忆        | 评审     | 可查可删、有来源与置信度               |

## 1. 模型出口

（PY-AI-001）模型调用只经统一出口：路由、超时、重试、用量记录都在出口内；业务代码不得直接实例化供应商 SDK。判定：形态检查 + 评审。

## 2. agent 循环契约

（PY-AI-002）运行状态机（排队/运行/待审批/成功/失败/取消/超时）与轨迹步骤是稳定契约：状态与转移集中定义一处；改动必须对照契约文档并更新场景清单，禁止在业务代码里分散改状态。判定：评审。

## 3. 结构化输出

（PY-AI-003）模型输出进入业务前必须过 Pydantic 校验；校验失败重试有限次（上限集中配置），超限按失败处理并记录原因。判定：测试。

## 4. 用量与成本

（PY-AI-004）每次模型调用记录：`requestId`、模型名、输入/输出/缓存 token、耗时、失败原因；按日聚合供成本核对。判定：评审。

## 5. prompt 安全

（PY-AI-005）密钥与凭据禁入 prompt、模板与日志；用户输入与外部文档只作为数据引用，不得作为指令注入系统提示；工具输出截断后再回填。

依据：`../common/05-安全.md` + OWASP LLM 应用风险——提示注入的入口正是用户可控内容与外部文档。

## 6. 工具与审批

（PY-AI-006）工具经注册表定义：名称、描述、参数 schema、风险等级；高危工具执行前必须审批；审批与执行留痕可审计。

## 7. 评测

（PY-AI-007）固定评测集三类：人格一致性、记忆召回、工具选择；agent 循环改动必须跑全量评测并入变更门禁。判定：变更门禁。

## 8. 记忆

（PY-AI-008）记忆写入可查可删：删除后物理移除，不保留副本；每条记忆带来源与置信度，低置信度不得向用户断言。

依据：本项目决策（记忆是隐私边界，可删性是底线）。
