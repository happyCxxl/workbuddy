# 03 · 异步与资源

> 本文件写异步边界、超时与资源所有权；与具体模块名无关。

## 1. 异步边界

（PY-ASYNC-001）IO 一律 `async`：HTTP、数据库、缓存、模型调用；CPU 密集与阻塞库调用进线程池（`anyio.to_thread` 或 `run_in_executor`）；`async` 函数内禁止阻塞调用（同步网络/磁盘 IO、`time.sleep`）。判定：ruff（ASYNC 规则）+ 评审。

（PY-ASYNC-002）所有外部调用必须带超时（HTTP、模型、数据库、缓存），超时值集中配置，禁止硬编码与无超时调用。判定：评审。

（PY-ASYNC-003）事件循环内禁止长任务：循环内的 CPU 密集处理一律进线程池或独立进程。

依据：FastAPI 官方文档「Concurrency and async / await」——阻塞调用会拖垮整个事件循环。

## 2. 资源所有权

（PY-ASYNC-004）连接池与客户端进程级复用：`httpx.AsyncClient`、数据库引擎、缓存客户端各建一份，随应用生命周期关闭；禁止每次调用新建。判定：评审。

（PY-ASYNC-005）文件、流、锁等资源用上下文管理器管理；SSE 生成器中断时释放持有的资源；服务关闭时优雅结束全部后台任务。等级【应该】。

（PY-ASYNC-006）后台任务（记忆抽取、用量聚合、定时执行）与请求路径隔离：请求内不得同步等待后台任务完成；失败重试与幂等按任务口径处理。等级【应该】。
