# 02 · 契约

> 全局契约（响应信封、HTTP 状态、分页、ID 序列化、幂等、请求追踪）与业务后端同口径，口径出处见 `../java/04-契约.md`；本文件只写 Python 落地形态。
> 错误码的登记规则见 `05-异常与日志.md`，码值分段在此声明。

| 小节           | 判定            | 具体怎么判                                                    |
|----------------|-----------------|---------------------------------------------------------------|
| 1 请求与响应   | 评审 + 类型检查 | 模型位置与「只承载字段」靠评审；字段类型靠 Pyright            |
| 2 校验         | 评审            | 结构校验在模型、业务校验在用例                                |
| 3 分页         | 评审            | `current`/`size` 与服务端上限                                 |
| 4 响应形态     | 形态检查        | 接口是否统一走信封（后续接检查器）                            |
| 5 全局契约口径 | 评审 + 单测     | ID 字符串、码值枚举由单测固定；恒 200、幂等、requestId 靠评审 |
| 6 流式契约     | 评审            | 事件类型枚举与字段固定                                        |

## 1. 请求与响应

（PY-DTO-001）请求/响应对象用 Pydantic `BaseModel` 定义，集中放接口层；模型只承载字段与结构校验，不写业务方法、不查库、不做状态判断。

## 2. 校验

（PY-DTO-002）请求体一律校验：结构校验（非空、长度、格式、范围）写在模型定义上；业务校验（唯一性、状态、权限）写在用例里；错误消息用中文；内部调用不重复校验上游已保证的条件。

依据：与 java 域校验口径一致（阿里安全规约第 4 条）。

## 3. 分页

（PY-DTO-003）分页参数名固定 `current` 与 `size`，响应返回统一分页结构；`size` 必须做服务端上限约束；排序字段必须走白名单，禁止请求参数直接拼进查询。

依据：与 java 域同口径（页大小过大导致内存溢出、恶意排序导致慢查询）。

## 4. 响应形态

（PY-DTO-004）返回 JSON 的接口一律用统一响应信封（状态码、消息、数据），不手动设置 HTTP 状态表达业务失败；列表与分页返回同一结构。二进制与文件流接口不受本条约束。

依据：统一信封是跨语言约定，作用于业务数据接口。

## 5. 全局契约口径

（PY-DTO-005）业务接口 HTTP 状态码恒为 200（网络层故障除外）；业务错误、参数错误、未认证、无权限一律 200 + 信封状态码表达。例外：SSE 流式接口与二进制/文件流接口。

依据：与 java 域同口径——裸 4xx 在浏览器侧拿不到可判断的业务码。

（PY-DTO-006）大整数 ID 按安全整数阈值序列化：超过 2^53-1 输出字符串；雪花 ID 一律字符串下发与回传；计数、耗时、分页号仍是数字。

依据：与 java 域同口径（JavaScript `Number` 安全整数上限）。

（PY-DTO-007）提交类写接口用幂等键 `requestId` 防重放：一次提交一个值，重试沿用；缺失返回登记的错误码；重放返回首次结果，不重复落库。

依据：与 java 域同口径（OWASP 幂等与重放防护）。

（PY-DTO-008）码值走枚举：状态、角色、类型只在枚举定义一处；解析未知码时，写路径报业务错误，读路径取保守语义。

依据：码值散落会导致同一状态在不同入口判定不一致。

（PY-DTO-009）请求追踪：`requestId` 从请求头透传，贯穿日志与模型调用明细；缺失时生成并回填。

（PY-DTO-010）二进制资源存对象存储，应用层只下发对象 URL，不做字节代理；公开读范围按前缀收窄。

依据：与 java 域同口径——应用层代理字节占用带宽与连接，且拿不到边缘缓存。

（PY-DTO-011）映射只做字段搬运：实体 → 出参对象显式构造（`model_validate` 或显式赋值），不查库、不做业务判断；一个映射一个方向。禁止在映射里散落分支与聚合。

依据：与 java 域同口径——映射出现分支就说明它已经不是映射。

## 6. 流式契约

（PY-DTO-012）SSE 事件结构固定：事件类型走枚举（内容增量、工具调用、审批、结束、错误），每类事件字段固定；断开重连与断点恢复口径在契约文档写明。

依据：单前端 shell 依赖统一事件模型，否则每类事件都要写一套分支。
