# ADR-0002：鉴权取舍——自建无状态 JWT，不做会话管理 / SSO / MFA

| 项   | 值                                                                          |
|------|-----------------------------------------------------------------------------|
| 状态 | 接受                                                                        |
| 日期 | 补录（口径确立早于本目录建立，依据 docs/README.md 已定口径与全局约定四~六） |

## 背景

workbuddy 自建登录（不假设平台共享身份能力）、无租户、用户规模有限；鉴权复杂度需要明确边界，防止范围蔓延。

## 决策

- 令牌：无状态 JWT（HS256），有效期两档（默认 1 天 / 记住我 30 天）；单张令牌不作废，改密 / 改角色 / 停用 / 删除靠 `token_version` 全量失效（每请求一次主键查询比对）。
- 明确不做：在线设备列表与单踢、SSO（AD / LDAP / OAuth）、MFA、Passay 密码复杂度策略（新密码长度统一 8-10 位）。
- 自助注册保持开放；登录失败防护按「账号+IP 为主、IP 为辅」双维度计数，锁定期间不查库不比对密码。
- 接口限流与登录防护的客户端 IP 只取 `getRemoteAddr()`，不读 `X-Forwarded-For`（可伪造；将来加反向代理时按可信代理白名单解析）。

## 备选与否决原因

- 服务端会话 / 在线设备管理：单体自用系统收益低，会话存储与管理成本不匹配。
- SSO / MFA：没有对接的组织身份源，需求不存在。
- 信任 `X-Forwarded-For`：请求头可伪造，等于把限流维度交给攻击者。

## 后果

- 鉴权链路简单、可审计；改密后该账号全部存量令牌即时失效。
- 单设备粒度的「踢出」做不到（只能全量失效）；将来前面加反向代理时，IP 解析口径要回头调整。
