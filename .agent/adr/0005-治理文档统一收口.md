# ADR-0005：工程治理文档统一收口 `.agent/`

| 项   | 值             |
|------|----------------|
| 状态 | 接受           |
| 日期 | 以提交日期为准 |

## 背景

- 治理类文档散布在六处：根 `CONTRIBUTING.md`、`web/docs/前端开发规范.md`、`web/docs/delivery-checklist.md`、`tools/README.md`、`tools/backend/README.md`、`tools/frontend/README.md`，加上 `.agent/adr/` 与 `.agent/standards/`。
- 同一类内容（规范条款、检查口径、协作流程、取舍记录）分散在三层目录，跨会话查找需要多跳；新增功能域时落位口径不统一。
- `tools/` 下说明文档与可执行脚本混放，检查口径与引擎配置不在同一层。

## 决策

1. 治理文档统一收口 `.agent/`，按用途分区：

| 目录                     | 内容                                                       |
|--------------------------|------------------------------------------------------------|
| `.agent/CONTRIBUTING.md` | 协作流程与规范迭代指南                                     |
| `.agent/standards/`      | 条款正典：`java/`、`frontend/`、`exemplars/`               |
| `.agent/checkers/`       | 检查口径：`README.md`（跨侧）、`backend.md`、`frontend.md` |
| `.agent/adr/`            | 取舍记录，只增不改                                         |

2. 入口保持双份：根 `AGENTS.md`（全库）与 `web/AGENTS.md`（前端就近），只留禁令与指针，条款正文不外溢。
3. `docs/` 只放业务文档；`tools/` 只放脚本与引擎配置（`checkstyle.xml`、`pmd-ruleset.xml`、`*.mjs`），不放说明正文。
4. `tools/check-agents.mjs` 的入口清单改为 `AGENTS.md`、`web/AGENTS.md`、`.agent/CONTRIBUTING.md`。
5. 新增功能域时：入口建在功能域目录，条款正文落 `.agent/standards/<域>/`。

## 备选与否决原因

| 备选                                                | 否决原因                                                 |
|-----------------------------------------------------|----------------------------------------------------------|
| 保持现状分散                                        | 同类内容三层目录，跨会话与跨机器查找多跳，落位口径靠记忆 |
| 只把新增的 `standards/` 放进 `.agent/`              | 前端规范与检查口径仍在别处，治理文档依旧不是单一入口     |
| 全部并入单个 `.agent/README.md`                     | 超出入口行数预算，条款无法分级与逐条挂执行者             |
| 根目录保留 `CONTRIBUTING.md` 再复制一份到 `.agent/` | 两份事实源，改动必漏一处                                 |
| 保留 `tools/*/README.md` 就地不动                   | 与「治理文档收口」目标冲突，规范与检查口径仍分两层       |

## 后果

- 治理文档单一入口：条款、检查口径、协作流程、取舍记录都在 `.agent/` 下。
- 根目录只留两个 AI 入口与业务文档入口，克隆后目录语义清晰。
- GitHub 对根 `CONTRIBUTING.md` 的自动提示不再生效；PR 模板、`AGENTS.md` §1 与 `README.md` 文档表已给指针。
- `check-agents.mjs` 的入口清单与 CI 保持一致；`.github/CODEOWNERS` 去掉 `/CONTRIBUTING.md` 一行，由 `/.agent/` 覆盖。
- 代价：`.agent/` 成为点目录，在部分编辑器与网页端需展开查看；入口指针的准确性依赖 `check-agents.mjs`。
