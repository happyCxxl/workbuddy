# ADR — 取舍记录（Architecture Decision Records）

> 一个决策一条文件：背景、决策、后果、被否掉的备选。代码与规范文档只描述现状，查取舍来历到这里。
> 本目录归 `.agent/`（代理与工程治理）管辖，与 `docs/`（业务文档）、`tools/`（检查器）互不混放。

- **只增不改**：决策变了新写一条，把旧条状态改为「被 ADR-XXXX 取代」，不原地改写。
- 命名 `NNNN-标题.md`，四位序号递增；新决策复制 `_template.md` 起草。
- 状态三档：接受 / 被取代（注明接替条目）/ 废弃。
- 触发场景（CONTRIBUTING §6 / §7）：技术选型、架构与契约口径变化、门禁规则增减、新功能域接入。
- 存量方案文档（`docs/design/` 的方案对比与设计）视作等价物，不回迁；新决策统一落本目录。
