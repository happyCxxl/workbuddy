# 难解析 PDF 样例集

解析环节回归基线：模型能力接入后的行为以这些样例为准，而非单文件调参。

| 文件 | 形态 | 验证点 |
|---|---|---|
| `scanned.pdf` | 整页图片（白底黑字两行） | 扫描页 → OCR 补文字，任务 PARTIAL_SUCCESS |
| `borderless-table.pdf` | 无边框四列表格 | 规则路径文本对齐建表；规则失败时表格能力补强 |
| `multi-column.pdf` | 双栏版面 | 栏沟切分与阅读顺序；跨栏形态时版面能力补强 |
| `mixed.pdf` | 第 1 页扫描图 + 第 2 页数字文本 | 页级触发：仅扫描页走 OCR，数字页走规则路径；组装环节裁决两路重叠 |

用法：解析这些文件并断言产物形态（元素类型、ocr 路覆盖页、能力快照、任务状态）。
样例由 PDFBox 程序化生成（生成器为一次性脚本，不随仓库保留）；改样例需重新生成并更新本表。
