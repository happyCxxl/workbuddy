# 07 · 接口

> 本文件回答：对外暴露什么契约。
> 概览级：列接口与用途，不复制参数与返回值定义——它们住在代码与接口文档里。

## 对外接口

| 接口                        | 类型 | 用途                           |
|-----------------------------|------|--------------------------------|
| `/auth/*`                   | HTTP | 登录、登出                     |
| `/user/*`                   | HTTP | 用户信息                       |
| `/user/avatar/*`            | HTTP | 头像                           |
| `/files/*`                  | HTTP | 文件上传与下载                 |
| `/system/storage-sources/*` | HTTP | 存储源管理                     |
| `/model/*`                  | HTTP | 模型目录与供应商               |
| `/knowledge-base/*`         | HTTP | 知识库增删改查、索引与检索入口 |
| `/home`                     | HTTP | 知识库首页概览                 |
| `/file-results/*`           | HTTP | 流水线各环节与血缘             |
| `/strategy-versions/*`      | HTTP | 策略版本管理与绑定             |

服务端口 4388；无统一网关前缀，前端经开发服务器代理访问。

## 内部契约指针

> 模块之间共享的类型定义与契约文档的位置。

- `workbuddy-common`：请求 / 响应 / 实体 / 枚举 / 错误码；码表与参数以实现枚举和配置类为准
- 规则：`JAVA-DTO-007`~`011`（HTTP 恒 200、ID 序列化、幂等键、数据形态、码值）、`JAVA-ERR-005/006`（错误码）、`COMMON-ANTI-05`（判空）、`JAVA-DTO-003`（分页）
