# 08 · 运行与部署

> 本文件回答：怎么跑起来、跑在哪、出了事从哪里看。

## 运行形态

> 单体 / 多实例、常驻服务还是任务制。

- 后端单体多模块、单进程；`biz` 为唯一可启动模块，服务端口 4388；前端 SPA 独立构建。
- 任务执行：进程内执行池 + Redis 队列；可多实例部署（限流与锁走 Redis）。

## 环境与部署

| 环境        | 部署方式                                                                                                                     | 配置来源                                                                     |
|-------------|------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------|
| 本地        | `cd docker && docker compose up -d` 起中间件；`mvn -o -pl workbuddy-biz spring-boot:run` 起后端；`cd web && pnpm dev` 起前端 | `workbuddy-biz/src/main/resources/application.yml` + `application-local.yml` |
| 测试 / 生产 | 无                                                                                                                           | —                                                                            |

中间件：MySQL、Redis、MinIO、Milvus（另含 etcd 与 workbuddy-minio 初始化容器）。

## 关键运行场景

> 启动、发布、回滚、数据备份分别怎么做。

- 启动：先起中间件（含 MinIO bucket 初始化），再起 `biz`，再起前端。
- 发布：无固定流程（本地运行）。
- 回滚：无。
- 备份：无。

## 可观测性

> 日志、监控、告警的现状：出问题从哪里看。

- 日志：应用日志（Spring 默认输出）；审计记录写入 `WbAuditLog` 表。
- 监控与告警：无。
