# 06 · 数据

> 本文件回答：数据长什么样、存在哪、怎么演进。
> 概览级：列核心实体与存储布局，不复制完整建表语句。

## 数据模型概览

> 核心实体与它们的关系。

- 21 张业务表（Wb 前缀）+ 1 个基础映射：

| 领域       | 实体                                                                                                                        |
|------------|-----------------------------------------------------------------------------------------------------------------------------|
| 用户与审计 | `WbUser`、`WbAuditLog`                                                                                                      |
| 知识库与源 | `WbKnowledgeBase`、`WbSourceFile`、`WbFileObject`、`WbFileResult`、`WbStorageSource`                                        |
| 流水线     | `WbPipelineTask`、`WbPipelineProduct`、`WbPipelineStepLog`、`WbPipelineStrategyVersion`、`WbStrategyBinding`、`WbSubmitLog` |
| 切片与向量 | `WbChunkSet`、`WbChunk`、`WbEmbeddingSet`、`WbEmbeddingRecord`                                                              |
| 索引与检索 | `WbIndexSet`、`WbIndexVersion`、`WbRetrievalRun`                                                                            |
| 模型       | `WbModel`                                                                                                                   |
| 基础映射   | `InfraBase`（MyBatis-Plus 基类，非业务表）                                                                                  |

## 存储布局

| 数据                    | 存储             | 说明                                                                  |
|-------------------------|------------------|-----------------------------------------------------------------------|
| 业务元数据              | MySQL            | 经 MyBatis-Plus 访问：`Wb*Mapper` + `Wb*DbService`                    |
| 队列 / 锁 / 计数 / 限流 | Redis            | `RedisQueueSupport`、`RedisLock`、`RedisCounter`、`BucketRateLimiter` |
| 原始文件与解析产物      | MinIO 或本地目录 | `file` 模块的 `StorageProvider`（Local / MinIO）                      |
| 向量                    | Milvus           | `vector` 模块，集合按索引版本管理                                     |
