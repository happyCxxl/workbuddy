# 03 · 约束

> 本文件回答：哪些东西是**给定的、不可协商的前提**。
> 约束与目标的区别：约束是「不能动的前提」，目标是「要达成的结果」。

## 技术约束

| 约束                                                  | 来源                                                 | 限制了什么                 |
|-------------------------------------------------------|------------------------------------------------------|----------------------------|
| Java 21 + Spring Boot 3.2.5（官方 starter parent）    | `workbuddy-server/pom.xml`                           | 全部后端语法与依赖版本     |
| Maven 多模块、包根 `com.workbuddy`                    | `workbuddy-server/pom.xml`                           | 目录结构与模块间依赖       |
| 前端 Vue 3 + TypeScript + Vite + Element Plus         | `workbuddy-web/package.json`                         | 前端实现形态               |
| MySQL / Redis / MinIO / Milvus 由 docker compose 提供 | `docker/docker-compose.yml`                          | 本地运行方式               |
| 不新增第三方依赖（任务明确要求除外）                  | `AGENTS.md` §2 Never#4                               | 依赖面保持稳定             |
| 禁止用 PowerShell 文本写入方式改仓库文件              | `AGENTS.md` §2 Never#1                               | 编辑方式（UTF-8 编码安全） |
| 对外 HTTP 恒 200，业务错误码统一登记                  | `JAVA-DTO-007`、`JAVA-ERR-005`；码表以错误码枚举为准 | 接口实现与前端处理         |
