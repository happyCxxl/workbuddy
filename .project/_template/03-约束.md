# 03 · 约束

> 本文件回答：哪些东西是**给定的、不可协商的前提**。
> 约束与目标的区别：约束是「不能动的前提」，目标是「要达成的结果」——前者划定方案空间的边界，后者在边界内选点。

填写规则：每条约束写清**来源**（谁或什么规定的——权威性来自来源）与**限制了什么**（对设计与实现的实际影响）。
没有内容的小节整节填「无」。
