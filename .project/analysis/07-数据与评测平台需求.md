# 07 · 数据与评测平台需求

> 状态：需求文档（草案）。本文只交代背景与需求，不含实现细节与选型理由。

## 1. 背景

- 平台按功能域扩展，功能域内的解析、检索等算法与模型，需要「数据集 + 评测」来度量质量并支撑调优。
- 需要一套统一能力：样本管理、金标标注、可复现运行、指标计算、对比报告、回归门禁。
- 骨架领域无关：任何功能域接入 = 注册一个标注 schema + 注册若干指标 + 写一个运行适配器，不改骨架。

## 2. 术语

| 术语                  | 含义                                                                                      |
|-----------------------|-------------------------------------------------------------------------------------------|
| 数据集 dataset        | 样本 + 版本 + 元数据 + split 的容器（原料），与用途无关                                   |
| 评测集 evaluation set | 数据集里 split ∈ {test, holdout} 且挂金标、用于算指标的部分；是数据集的用途，不是独立实体 |
| 样本 item             | 被评测的最小单元（文档、页面、查询、切片集等）                                            |
| 金标 annotation       | 样本的标准答案，结构按功能域定义                                                          |
| 运行 run              | 一次「某版本数据集 × 某版本管线」的执行记录                                               |
| 指标 metric           | 对运行结果的量化评价，注册口径与方向                                                      |
| 对比 comparison       | 两个 run 的指标与逐项 diff 报告                                                           |
| split                 | 样本用途划分：train / dev / test / holdout                                                |
| 留出集 holdout        | 不参与调参、仅最终验证的样本子集                                                          |

## 3. 需求

优先级：P0 = 首版必须；P1 = 首版后尽快；P2 = 视规模再定。

### 3.1 数据集管理

| 编号 | 需求                                                                             | 优先级 |
|------|----------------------------------------------------------------------------------|--------|
| DS-1 | 支持登记数据集（名称、所属功能域、说明）                                         | P0     |
| DS-2 | 数据集版本不可变：改样本必须升版本；版本含样本数、清单摘要、状态（draft/frozen） | P0     |
| DS-3 | 样本 item 登记：对象键、MIME、大小、摘要、来源、split、元数据                    | P0     |
| DS-4 | 样本文件不进代码库；代码库只存清单（摘要 + split + 期望指标）                    | P0     |
| DS-5 | 样本来源分类：内部真实、用户反馈、公开集导入、构造                               | P0     |
| DS-6 | 用户反馈可登记为样本并挂缺陷标签                                                 | P1     |
| DS-7 | 公开集导入（外部基准数据转换对齐到本平台契约）                                   | P1     |

### 3.2 标注

| 编号 | 需求                                                      | 优先级                 |
|------|-----------------------------------------------------------|------------------------|
| AN-1 | 标注 schema 按功能域注册（定义金标结构），带版本          | P0                     |
| AN-2 | 金标落库：样本 × schema × 负载 × 标注人 × 状态            | P0                     |
| AN-3 | 状态机：预标 → 草稿 → 已审 → 争议；指标只算「已审」及以上 | P0                     |
| AN-4 | 机器预标：用当前算法结果生成草稿，人工只改错处            | P1                     |
| AN-5 | 分级标注：先标页级（类型/难度），再补块级（框/表格）      | P0（页级）/ P1（块级） |

### 3.3 评测运行

| 编号 | 需求                                                                     | 优先级 |
|------|--------------------------------------------------------------------------|--------|
| EV-1 | 运行登记：数据集版本 × 功能域 × 管线版本（代码/配置/模型版本哈希）+ 状态 | P0     |
| EV-2 | 逐样本运行项：样本 × 产物 × 耗时 × 成本 × 错误/降级                      | P0     |
| EV-3 | 可复现：run 记录完整版本快照，同一输入重跑结果一致                       | P0     |
| EV-4 | 运行器按功能域路由，不经线上链路、串行执行、产物落存储                   | P0     |
| EV-5 | 失败隔离：单样本失败不中断整批，报告区分「运行失败」与「质量差」         | P0     |

### 3.4 指标与对比

| 编号 | 需求                                                                                                      | 优先级                                           |
|------|-----------------------------------------------------------------------------------------------------------|--------------------------------------------------|
| ME-1 | 指标注册：名称、口径、方向、聚合粒度（样本/数据集）                                                       | P0                                               |
| ME-2 | 指标落库：run × 范围 × 样本 × 指标 × 值；重复计算幂等                                                     | P0                                               |
| ME-3 | 支持按功能域注册指标族，示例：解析（文本保真、块检测、阅读顺序、表格结构）、检索（Recall@k、MRR、nDCG@k） | P0（质量）/ P1（工程指标：降级率、直通率、耗时） |
| ME-4 | 对比报告：基线 vs 候选，逐项 diff + 指标 diff + 不劣化判定                                                | P0                                               |

### 3.5 门禁

| 编号 | 需求                                                     | 优先级 |
|------|----------------------------------------------------------|--------|
| GA-1 | 快集/全量两档：快集小样本、短时、本地；全量按需          | P0     |
| GA-2 | 不劣化判定：候选相对基线至少一项上升且无下降，否则需说明 | P0     |
| GA-3 | 留出集隔离：不参与调参，仅最终验证                       | P0     |
| GA-4 | 回归用例固化：已修缺陷转回归 case                        | P0     |
| GA-5 | 公开集与内部集分开报分                                   | P0     |

### 3.6 Web UI

| 编号 | 需求                                                                   | 优先级 |
|------|------------------------------------------------------------------------|--------|
| UI-1 | 数据集与样本管理页（增删查、来源/split 展示、导入入口）                | P0     |
| UI-2 | 标注页（金标查看与表单编辑）                                           | P0     |
| UI-3 | 运行与报告页（发起运行、状态、指标总览、逐项 diff、指标 diff、不劣化） | P0     |
| UI-4 | 回归门禁页（结果、通过/拦截、下钻）                                    | P1     |

### 3.7 非功能

| 编号 | 需求                                           | 优先级 |
|------|------------------------------------------------|--------|
| NF-1 | 新增第三方依赖需单独评审                       | P0     |
| NF-2 | 数据库结构变更需版本化、可重建                 | P0     |
| NF-3 | 敏感样本需脱敏；外部服务调用需审批，密钥不入库 | P0     |
| NF-4 | 环境可重建，路径不写死                         | P0     |
| NF-5 | 报告可下钻到「哪一项、哪个指标、差多少」       | P0     |

## 4. 里程碑

| 里程碑 | 内容                                                        | 验收                                                           |
|--------|-------------------------------------------------------------|----------------------------------------------------------------|
| M1     | 骨架（数据集/标注/运行/指标/对比）+ 首个功能域接入 + Web UI | 一轮「上传 → 标注 → 运行 → 看报告」闭环；改动前后可出指标 diff |
| M2     | 第二个功能域接入                                            | 该域改动前后有指标对比                                         |
| M3     | 采集闭环 + 公开集导入 + 机器预标                            | 样本量达标；公开/内部分开报分                                  |
| M4     | 支撑模型选型与阈值标定                                      | 模型/阈值切换有量化结论                                        |

## 5. 待确认

- 起步样本量
- 留出集占比
- 敏感样本脱敏边界
- 不劣化基线口径

## 6. 验收标准

1. 同一数据集版本 + 同一管线版本，重跑指标完全一致。
2. 改动前后可输出逐项 + 逐指标 diff，可下钻到样本。
3. 已修缺陷固化为回归 case，改坏时门禁能拦下。
4. 新功能域接入不改骨架，只加 schema + 指标 + 运行适配器。
