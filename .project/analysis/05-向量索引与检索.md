# 向量化、索引与检索：现状、问题与优化方案

> 本文件是 `.project/analysis/` 专题分册之一，覆盖 EMBED（向量化）、BUILD_INDEX（索引构建）与检索。
> 结论基于源码静态审查，未启动服务、未运行测试；未运行时验证的判断标 `[推断]`。

## 1. 环节职责与边界

### 1.1 向量化（EMBED）

- 输入：CHUNK 产物 `ChunkSet` + 向量化策略快照；
- 输出：`EmbeddingSet` JSON + `wb_embedding_set` / `wb_embedding_record`；
- 职责：前置窗口校验、输入文本渲染、账本复用、分批调用灵犀 `/internal/v1/embed`、四关校验；
- 不负责：索引写入；成功后回调 `IndexSetService.onFileProductsReady`。

### 1.2 索引（BUILD_INDEX）

- 输入：PREPROCESS + CHUNK + EMBED 三产物组合；
- 输出：Milvus 集合 + 索引版本行 + 发布状态；
- 职责：版本定位/注册、集合 ensure/load、追加行、批次对账、READY/发布；
- 手动路径：`buildCandidate` / `LIST` / `COMPENSATE` 走 `BUILD_INDEX` 任务。

### 1.3 检索

- 输入：query + 知识库/版本/规则；
- 输出：命中快照 `wb_retrieval_run`；
- 职责：版本解析、规则解析、全文/向量召回、RRF 融合、父片展开、topK；
- 不负责：答案生成。

## 2. 真实执行流程

### 2.1 向量化

1. `EmbedTaskRunner` 读 CHUNK 产物 + 策略快照；
2. `EmbedPipeline` 前置校验：模型目录、窗口、维度；
3. 父片（SECTION）默认标 `SKIPPED`（`includeParent=OFF`）；
4. `IdentityTemplate.render()` 原样返回 `chunk.content`；
5. 同文件同策略账本按 `inputTextHash` 复用，命中则 `CACHED`；
6. 未命中分批调用灵犀 `/internal/v1/embed`，指数退避；
7. 四关校验：数量/维度/空值/度量归一化；
8. 落 `EmbeddingSet` + `wb_embedding_set` / `wb_embedding_record`；
9. 成功回调 `IndexSetService.onFileProductsReady`。

### 2.2 索引

增量路径（文件产物就绪回调）：

1. 按“PREPROCESS + CHUNK + EMBED”组合定位/注册版本；
2. ensure/load 集合；
3. `IndexRowSupport` 只取 `SUCCESS`/`CACHED` 记录，`content = record.inputText`；
4. append/upsert 到 Milvus；
5. 批次对账，只 `log.warn`；
6. 无条件置 READY；
7. 按绑定自动发布。

手动路径：

- `buildCandidate`：建 `BUILD_INDEX` 任务，入 Redis；
- `LIST`：列候选/版本；
- `COMPENSATE`：回退补齐；
- 但 `BUILD_INDEX` 没有消费者，任务永远 QUEUED（详见 V-07）。

### 2.3 检索

1. 版本解析：生产 = 在线版本；测试台 = 显式 READY/ONLINE；
2. 规则解析：显式 ruleId → version default → KB default → baseline；
3. 全文召回：Milvus `content_sparse`（BM25）；
4. 向量召回：调用 `embedQuery()` 得查询向量；
5. 融合：RRF 或直通；
6. 后处理：父片展开（`PARENT_EXPAND`）、topK；
7. 记录命中快照。

| V-12 | 检索评测没有指标                     | `WbRetrievalRun` 只存 query + 结果快照 + 耗时；`compareRuns` 只并排回放                                                                                                       | 无法量化质量，无法给 rerank/阈值/模型切换做门禁                         | 评测缺失   |

| V-17 | `title_path_sparse` 从不被检索       | schema 建了 `title_path` 的 BM25 sparse，但检索只查 `content_sparse`                                                                                                          | 标题字段白建，标题命中无法单独加权                                      | 索引模型   |

## 4. 根因

1. 查询侧与文档侧不对称：文档侧有 `EmbeddingClient`，查询侧只有占位；检索链路按“双通道”设计，实际只跑单通道。
2. 向量化记录与索引行不是同一集合：`IndexRowSupport` 只取 SUCCESS/CACHED，父片被 `SKIPPED`，导致“切片有父片、索引没父片”。
3. 模板/度量/超时/模型目录四套配置没有单一事实源：策略 JSON、Java 枚举、全局 yml、灵犀目录各自定义。
4. 索引是 append-only 账本，不是可重建物化视图：无 delete/compaction，chunkId 是序号，READY 不等待全量对账。
5. 检索能力“先锁后实现”：`RetrievalCapability` 预留了 RERANK/REWRITE/EXPAND/WEIGHTED/SCORE_THRESHOLD，但没有执行代码；灵犀接口已存在，Java 侧未接。
6. 评测只存“跑了什么”，不存“对不对”：没有标注表、指标计算、基线对比。

## 6. 优化方向

### 6.1 先跑通

1. **`BUILD_INDEX` 消费**：扫库阶段加 BUILD_INDEX，dispatch 加分支；补 `buildCandidate → READY` 集成测试；修补偿器空转。
2. **查询向量化**：`EmbeddingClient` 增加 `inputType`，检索侧用 `queryTemplate` 渲染后调用；失败显式标记通道降级。
3. **父片链路**：索引父片行，或父片展开改读 CHUNK 产物；`parentChild`/`includeParent` 组合校验。
4. **失败重跑**：任务表加 `attempt` 或重触发接口；允许 FAILED 任务生成新执行。
5. **索引一致性**：READY 前全量对账；append/对账失败 → FAILED；加删除/按文档重建。
6. **配置贯通**：策略保存时回填 dimension/metric/window；`ensureCollection` 传 metric；`EmbedAlgorithmSpec` 与 Milvus schema 对齐。

### 6.2 再提质量

7. **模板渲染**：实现 `{titlePath}/{contentType}/{tableRef}` 或删掉承诺；渲染结果参与缓存键。
8. **缓存键**：加入模型/模板/维度/归一化版本；模型升级自动失效。
9. **超时/重试**：策略 timeout 透传到灵犀；客户端按策略而非全局；批量失败可重试。
10. **检索能力**：接灵犀 `/rerank`；实现 WEIGHTED/SCORE_THRESHOLD；全文分数保留；`title_path_sparse` 纳入召回或删除。
11. **过滤维度**：按业务需要加 page/section/tag/时间倒排。
12. **可用性**：检索超时/重试/降级；一致性级别可配置。

### 6.3 评测驱动

13. **标注集**：query → 相关 chunk → 相关性等级；
14. **指标**：Recall@k/MRR/nDCG@k/P95；
15. **门禁**：规则/模型/切片变更必须跑评测；
16. **对比**：基线 vs 候选，记录配置/代码版本/哈希。

## 7. 讨论清单

| 顺序 | 讨论项           | 需要确认的取舍                                     |
|------|------------------|----------------------------------------------------|
| 1    | BUILD_INDEX 消费 | 扫库阶段加还是独立消费者；超时/并发                |
| 2    | 查询向量化       | inputType 字段；queryTemplate 默认值；失败降级标记 |
| 3    | 父片             | 入索引 vs 展开读产物；父片长度上限                 |
| 4    | 索引删除         | 按文档删除 vs 版本重建；chunkId 稳定策略           |
| 5    | 度量             | 是否允许 IP/L2；集合重建成本                       |
| 6    | 模型目录         | Java 枚举 vs 灵犀 catalog；启动时拉取              |
| 7    | 缓存键           | 是否包含模板/模型/维度；旧缓存迁移                 |
| 8    | 超时             | 策略级 vs 全局；灵犀是否支持 timeout_ms            |
| 9    | rerank/加权/阈值 | 先评测再开关；默认值                               |
| 10   | 评测集           | 标注规模/来源；指标门槛                            |
