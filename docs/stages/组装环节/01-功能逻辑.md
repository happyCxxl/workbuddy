# 组装环节 · 功能逻辑

从「管线拿到上游解析产物」到「产出统一文档与建议状态」的完整口径。页面与接口视角（卡片四态、体检清单、四个接口的字段与错误码）见 `../../pages/组装环节/`。本文件不写接口字段与页面交互。

配套流程图（浏览器打开，节点带代码溯源）：环节总览 [`02-流程图-环节总览.html`](02-流程图-环节总览.html)；七道工艺 [`03-流程图-七道工艺.html`](03-流程图-七道工艺.html)。

## 一、环节边界

| 项   | 值                                                                                                            |
|------|---------------------------------------------------------------------------------------------------------------|
| 输入 | `AssembleContext`（`taskId` / `fileResultId` / 源文件类型 / 组装阈值）+ 上游解析产物 `ParseResult`            |
| 输出 | `UnifiedDocument`（`documentInfo` / `pages` / `elements` / `relations` / `quality`）+ 步骤日志清单 + 建议状态 |
| 触发 | 任务编排领取组装任务后调用 `AssemblerPipeline.assemble`（触发接口与任务状态机见页面侧文档）                   |
| 下游 | 预处理环节消费元素与页标记；切片、向量化、检索沿执行链继续                                                    |
| 不做 | 不碰 DB 与对象存储（纯算法）、不剔除任何内容（重复与噪声只标记，处置在预处理环节）、不做 OCR 与版面模型推理   |

`AssemblerPipeline` 的骨架固定，变化点在两处策略：标题规则链（`TitleRule` 的多个实现，按 `order()` 升序）与模型判定能力（`StructureJudgeProvider` 的实现列表，当前为空）。

## 二、七道工艺

`AssemblerPipeline.assemble` 顺序固定，步骤日志用 `StepLogHelper.begin` / `finish` 记录，步骤名取 `StructureStepName`：

| 序 | 步骤（`StructureStepName`）               | 做什么                                                                                                     | 失败后果                                                    |
|----|-------------------------------------------|------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------|
| ①  | `NORMALIZE`（元素标准化）                 | 解析元素 → 统一元素：类型映射、全局 ID、单元格嵌套、扩展区与溯源透传、目录行标记                           | 未识别类型只跳过并计数，不中断                              |
| ②  | `DEDUP_ORDER`（去重与阅读顺序）           | `DedupMergerImpl` 跨来源去重合并 → `ReadingOrderResolverImpl` XY-cut 排序                                  | 冲突只记录（PRIMARY / BACKUP），不中断                      |
| ③  | `ASSEMBLE_CONTINUATION`（结构组装与接续） | `StructureAssemblerImpl.assembleTree` 标题推定 + Excel 章节插入 → `TableContinuationResolverImpl` 续表接续 | 不中断                                                      |
| —  | （关系重建，同一日志内）                  | `StructureAssemblerImpl.buildRelations`：按**最终元素表**重建章节树 / 阅读顺序 / 单元格归属                | 不中断                                                      |
| ④  | `VERIFY_PROVENANCE`（溯源校验）           | 统计可回溯元素占比（自身或单元格带定位；结构性节点不计入分母）                                             | 比例低于阈值 → 质量告警，不中断                             |
| ⑤  | `MARK_REPEAT_NOISE`（重复与噪声识别）     | `RepeatNoiseMarkerImpl`：重复页 / 重复段 / 噪声页标记，逐页原因进日志                                      | 不中断                                                      |
| ⑥  | 质量与空树判定                            | 组装 `quality`（冲突 + 五类告警）；元素为空 → `STRUCTURE_EMPTY`                                            | 空树 → `FAILED`，其余 `SUCCESS`（不产出 `PARTIAL_SUCCESS`） |

补充口径：

- **整体只有一个硬失败**：元素为空（空树）落 `STRUCTURE_EMPTY`；其余异常由 biz 侧兜底成 `STRUCTURE_FAILED`（错误文案带异常类名，不落 `null`）。
- **关系构建放在接续之后**：接续会移除被并入的表格，关系若在接续前建好就会指向已删元素；重建保证关系端点都落在存活元素上。
- 同一文件可多次触发组装，每次运行各自成任务与产物，旧任务与旧产物保留。

## 三、元素标准化（①）

- **类型映射**：解析侧 `ElementType` → 统一侧 `UnifiedElementType`；两侧枚举不匹配的类型**跳过该元素并计数**（按类型名聚合），产物质量区落 `ELEMENT_TYPE_UNMAPPED` 告警（含类型清单与跳过元素数）。
- **全局 ID**：`类型前缀 + 内容哈希`（`StructureIds`），同一元素在同一产物内稳定；接续合并后保留首页元素 ID。
- **单元格嵌套**：表格的 `cells` 递归标准化（单元格自身的类型与溯源一并保留），顶层元素表只放表格本身。
- **扩展区透传**：解析侧扩展键原样带入（样式名、sheet 名、`cutAtPageBottom`、`headerRow`、来源路名与解析器名等），组装侧新增键统一走 `ElementExtensionKey`。
- **来源键语义**：`source` = 来源路名（`native` / `ocr` / …），`provider` = 具体解析器（如 `pdfbox-3.0.4`）；ID 种子取 `provider`，去重取舍与排序按 `source`。
- **目录行标记**：解析侧带目录特征的段落标 `ElementMark.TOC_LINE`，供预处理环节的目录规则消费。

## 四、去重与合并（②之一）

- **双判定**：几何 IoU 超阈值**且**文本相似度超阈值 → 视为同一元素，按来源顺序取舍；两条都不过 → 两个都留。
- **同框不同内容**：IoU 超阈值但文本不相似 → 两路都留，标 `PRIMARY` / `BACKUP` 并写冲突记录（记录含 IoU 与相似度数值）。
- **来源顺序**：`SOURCE_PRIORITY` 给出路名次序，未知来源排最后（`priorityOf` 对缺失来源返回最大值）；该顺序是**过渡口径**，接入第二路后改按证据裁决。
- **可追溯**：合并与冲突都计入 `AssembleReport`（`mergePairs` / `conflictCount`），被弃元素进冲突记录之外不落产物。

## 五、阅读顺序（②之二）

- **XY-cut**：按页分组后投递归切分——行带间距超过 `xyCutBandGapRatio × 行高` 切段，块间距超过 `xyCutBlockGap` 切块；同页内按「段 → 块 → 行 → 元素」输出。
- **无坐标元素直通**：没有 `bbox` 的元素按原顺序追加在末尾（`withoutBboxCount` 是这一口径的观测值）。
- **多页顺序**：页按页码升序，页内按坐标重排；`pageRange` 表达的跨页元素按其首页参与排序。
- **页眉页脚**：`HEADER` / `FOOTER` 留在元素表里，但不进 `NEXT` / `PREVIOUS` 正文链。

## 六、结构组装（③）

**标题推定规则链**（按 `order()` 升序，命中即止）：

| 序 | 规则（`TitleRule`）     | order | 判据                                                          |
|----|-------------------------|-------|---------------------------------------------------------------|
| 1  | `StyleTitleRule`        | 10    | 原生样式名锚定 `HeadingN`（`Heading0` 不算），级数收敛到 1~9  |
| 2  | `ChapterTitleRule`      | 20    | 「第X章 / 第X节」这类章节编号                                 |
| 3  | `SingleNumberTitleRule` | 25    | 单级编号 + 非数字正文（`1、总则`、`2. 范围`）                 |
| 4  | `NumberTitleRule`       | 30    | 多级编号（`1.2.3`），需含 CJK 且有字号佐证才定级              |
| 5  | `CnParenTitleRule`      | 40    | 中文括号编号（`（一）总则`）                                  |
| 6  | `CnDotTitleRule`        | 50    | 中文顿号编号（`一、总则`）                                    |
| 7  | `FontSignalTitleRule`   | 60    | 短句 + 加粗 + 字号 ≥ 中位数 × `fontSignalSizeRatio`（最弱层） |

- **字号佐证**：加粗，或字号 ≥ 文档中位数 × `fontBackedSizeRatio`；中位数只统计段落字号。
- **候选告警**：像标题但证据不足的短句记 `TITLE_CANDIDATE`（计入 `AssembleReport.titleCandidateCount`），不改类型。
- **模型兜底**：规则全 miss 且开关打开、且有实现时调用 `StructureJudgeProvider`，命中则按模型给定层级定级，证据串记「模型名@版本 conf=置信度」（版本或置信度缺失时不拼空值）。
- **Excel 章节**：按 `sheetName` 生成 `SECTION` 节点并**紧邻该 sheet 的首个元素插入**（顺序为 章节1、表1、章节2、表2…），同级章节互为兄弟。

**关系重建**（`buildRelations`，在接续之后执行）：

| 关系                | 口径                                                                                             |
|---------------------|--------------------------------------------------------------------------------------------------|
| `PARENT_CHILD`      | 标题 / 章节挂到最近的上层节点；纯数字章节按平台章节计；Excel 章节→表格的关系说明为「sheet 归属」 |
| `NEXT` / `PREVIOUS` | 阅读顺序链（排除 `HEADER` / `FOOTER`），相邻两两成对                                             |
| `TABLE_CELL_OF`     | 每个单元格归属到最终元素表里的表格（含接续并入的单元格）                                         |
| `CONTINUATION_OF`   | 由接续工艺产出（端点带 `#p页码` 后缀）                                                           |

## 七、跨页续表接续（③之二）

仅 PDF 表格参与，判定分主规则与放宽规则：

| 门槛     | 口径                                                                                                                                           |
|----------|------------------------------------------------------------------------------------------------------------------------------------------------|
| 页相邻   | 下页页首与当前末页相邻（按合并结果的末页比较）                                                                                                 |
| 上页表尾 | 上表扩展区 `cutAtPageBottom` 为真                                                                                                              |
| 下页页首 | 下表 `bbox.y` < `pageTopThreshold`                                                                                                             |
| 列数     | 两侧 `cols` **已知且相同**；任一侧缺失时不进主规则，落放宽规则                                                                                 |
| 表头     | 两侧表头行可读（`headerRow` 非空且该行有单元格）且 Jaccard ≥ `continuationHeaderSimilarity`                                                    |
| 放宽规则 | 参考行（表头可读用表头行，不可读用首行）列宽逐列相差 ≤ `continuationColumnWidthTolerance`，命中率 ≥ `columnWidthMatchRatio` → 合并但标**疑似** |

- **合并结果**：保留首页 `page` 与 `bbox`；跨页位置由 `pageRange` / `bboxes` 逐页累积；同一张表可链式跨任意页数（游标式合并）。
- **行号重编号**：续页行按保留行序号顺延，行数 = 声明行数 − 实际丢弃的表头行数；表头行判定为「`headerRow` 非空且行号相等」。
- **`headerInherited`**：只在确实丢弃了续页表头行时置真。
- **疑似计数**：放宽规则命中计入 `ContinuationOutcome.suspectedCount`，产物落 `SUSPECTED_CONTINUATION` 告警。

## 八、溯源校验（④）

- **可回溯**：元素自身带「文件引用 + 定位路径」，**或其单元格带**（表格经由单元格定位回原文）。
- **分母**：排除结构性节点（`SECTION`，组装环节自造）后的元素数；占比写进 `AssembleReport.traceableRatio`。
- **阈值**：可回溯占比低于 `provenanceLowPercent`（默认 80）时落 `PROVENANCE_MISSING` 告警，文案带阈值与缺失元素数；详情页结论文案用同一阈值。
- **理由**：主流解析器只给叶子（段落 / 单元格）写定位，容器（表格）没有；按"能否回指原文"判定而非"字段挂在谁身上"。

## 九、重复与噪声识别（⑤）

| 标记                       | 判据                                                                                                                     |
|----------------------------|--------------------------------------------------------------------------------------------------------------------------|
| `REPEATED_PAGE`（页）      | 页文本 bigram Jaccard > `repeatPageJaccard`（与该页之前的所有页比较，除首份外标记）                                      |
| `REPEATED_SEGMENT`（元素） | 文本元素（`PARAGRAPH` / `TITLE`）与之前**未判重复**的元素比较 > `repeatSegmentSimilarity` 且长度 ≥ `repeatSegmentMinLen` |
| `NOISE_PAGE`（页）         | 无元素页 / 仅图片页 / 乱码率 > `noiseGarbledRatio`；页覆盖范围按 `pageRange` 计，跨页表覆盖的页不判空白                  |

- **判定语义**是"与之前所有同类项逐个比 Jaccard"，实现上按集合规模分桶剪枝（Jaccard 上界 = min/max）、集合按需从原文重建不常驻、配容量有界的缓存（`repeatSetCacheSize`），另加「集合指纹相同且集合相等」的精确快车道。
- **只标记不删**：标记写进元素 / 页的 `marks`，处置（剔除出检索文本）在预处理环节的重复与噪声规则里。
- **噪声原因**：逐页原因（`页 N 空白页（无任何元素）` 这类）全量进日志；产物告警取「计数 + 最多 3 条样例 + 等」。
- **页路径范围**：仅 PDF（有页概念）；Word / Excel 跳过页级，重复段照做。

## 十、质量与失败语义（⑥）

| 告警码                   | 触发条件                                       |
|--------------------------|------------------------------------------------|
| `TITLE_CANDIDATE`        | 标题候选数 > 0（像标题但证据不足）             |
| `SUSPECTED_CONTINUATION` | 放宽规则命中的疑似续表数 > 0                   |
| `PROVENANCE_MISSING`     | 可回溯占比低于 `provenanceLowPercent`          |
| `NOISE_PAGE`             | 噪声页数 > 0（文案带样例页码）                 |
| `ELEMENT_TYPE_UNMAPPED`  | 未识别类型数 > 0（文案带类型清单与跳过元素数） |

- **建议状态只有两种**：`SUCCESS` 与 `STRUCTURE_EMPTY`（失败）；不产出 `PARTIAL_SUCCESS`。
- **失败归口**（biz 侧）：上游产物缺失 / 读不到 / 反序列化失败 → `STRUCTURE_UPSTREAM_UNREADABLE`；空树 → `STRUCTURE_EMPTY`；其余执行异常 → `STRUCTURE_FAILED`。上游文件或文件结果已不存在（`FILE_NOT_FOUND` / `FILE_RESULT_NOT_FOUND`）不论从哪条路径冒出都归"上游不可读"。
- **失败文案**：业务异常用其原因；其它异常带异常类名；消息为空时退化为类名（不落字面量 `null`）。
- **入队失败**：新任务写不进队列时落 `FAILED`(`TASK_ENQUEUE_FAILED`)，异常继续抛给触发接口；`QUEUED` 任务的补投由 `TaskStartupCompensator` 负责，触发入口不做唤醒。

## 十一、产物契约

`UnifiedDocument` 五个区块：

| 区块           | 内容                                                                                               |
|----------------|----------------------------------------------------------------------------------------------------|
| `documentInfo` | `documentId`（`doc-{fileResultId}`）、源文件引用与类型、上游解析运行 ID、`schemaVersion`、能力快照 |
| `pages`        | 页面基准（页码、宽高、旋转、单位 `pt`、原点左上）；Excel 为空                                      |
| `elements`     | 统一元素列表（顶层）；表格的单元格嵌在 `cells` 里                                                  |
| `relations`    | 章节树 / 阅读顺序 / 单元格归属 / 续表接续                                                          |
| `quality`      | 冲突记录 + 五类告警（`warnings`）                                                                  |

元素字段要点：

| 字段                                                        | 口径                                                                 |
|-------------------------------------------------------------|----------------------------------------------------------------------|
| `id`                                                        | 类型前缀 + 内容哈希                                                  |
| `type` / `text`                                             | 统一类型（`UnifiedElementType`）与文本                               |
| `page` / `bbox` / `pageRange` / `bboxes`                    | 单页位置 + 跨页范围与逐页分段框（分段框当前无生产读取方）            |
| `font` / `level` / `titleEvidence`                          | 字体事实、标题层级与推定证据（级联层 / 模式 / 字号 / 加粗 / 模型串） |
| `rows` / `cols` / `headerRow` / `cells` / `headerInherited` | 表格结构事实（接续合并后为最终值）                                   |
| `marks` / `extension` / `provenance`                        | 标记、扩展键（样式 / sheet 名 / 来源路名…）、原文定位                |

枚举口径：`UnifiedElementType`（含 `SECTION` 这类组装自造节点）、`RelationType`、`ElementMark`、`PageMark`、`ElementExtensionKey`、`StructureStepName`；`schemaVersion` 变更走版本（新增字段保持向后兼容，破坏性变更递增版本并同步下游）。

## 十二、阈值清单

`StructureProperties`（前缀 `knowledge.structure`，均可被同名配置覆盖）：

| 键                                 | 默认  | 用途                                       |
|------------------------------------|-------|--------------------------------------------|
| `iouThreshold`                     | 0.3   | 去重几何 IoU 阈值                          |
| `textSimilarityThreshold`          | 0.7   | 去重文本相似度阈值                         |
| `xyCutBandGapRatio`                | 1.5   | XY-cut 行带间距 ÷ 行高                     |
| `xyCutBlockGap`                    | 12.0  | XY-cut 块间距（pt）                        |
| `continuationHeaderSimilarity`     | 0.8   | 续表表头一致阈值                           |
| `continuationColumnWidthTolerance` | 3.0   | 续表放宽规则列宽容差（pt）                 |
| `columnWidthMatchRatio`            | 0.6   | 续表放宽规则列宽命中率下限                 |
| `pageTopThreshold`                 | 50.0  | 页首判定（表格 `bbox.y` 低于它算页首）     |
| `titleCandidateMaxLength`          | 40    | 标题候选短句长度上限                       |
| `fontBackedSizeRatio`              | 1.05  | 字号佐证比例（≥ 中位数 × 该值）            |
| `fontSignalSizeRatio`              | 1.15  | 字号/加粗规则比例                          |
| `repeatPageJaccard`                | 0.95  | 重复页判定阈值                             |
| `repeatSegmentSimilarity`          | 0.9   | 重复段判定阈值                             |
| `repeatSegmentMinLen`              | 50    | 重复段最小长度（字符）                     |
| `noiseGarbledRatio`                | 0.4   | 噪声页乱码率阈值                           |
| `provenanceLowPercent`             | 80    | 溯源偏低阈值（百分比，产物告警与结论同源） |
| `repeatSetCacheSize`               | 64    | 按需重建的 bigram 集合缓存条数上限         |
| `modelFallbackEnabled`             | false | 模型判定兜底开关                           |

任务侧阈值见 `TaskQueueProperties`（前缀 `knowledge.task`）：`compensateThreshold` 5 分钟（补投门槛）、`lowFreqSweepEnabled` 默认开启、`lowFreqSweepInterval` 1 分钟（滞留兜底）、`sweepLockTtl` 30 秒（多实例锁）、`shutdownWait` 30 秒（停机等上限）、`timeout.*` 各环节单任务超时（`parse`/`structure`/`preprocess`/`chunk` 5 分钟，`embed`/`build-index` 10 分钟）。`timeoutOf` 对环节名做归一化（小写 + 下划线转连字符），`BUILD_INDEX` ↔ `build-index`、`EMBED` ↔ `embed` 均能命中。消费侧两个线程池是具名 `ThreadPoolTaskExecutor` bean（`taskWatchdogExecutor` / `taskRunnerExecutor`，见 `TaskExecutorConfig`），daemon 线程、有界优雅关闭取 `shutdownWait`；Spring Boot 自动打点 `executor.*` 指标，`/actuator/health` 免认证、`/actuator/metrics` 需携带凭证。

## 十三、能力预留与当前边界

| 能力                              | 现状                                                              |
|-----------------------------------|-------------------------------------------------------------------|
| 模型判定（标题 / 续表）           | 契约、注册表、开关齐备，**零实现**；接入只需一个实现类 + 打开开关 |
| 多路解析结果（OCR / 版面 / 表格） | 去重合并与来源键语义已就位，当前只有原生一路；触发与裁决口径未定  |
| 跨页位置表达                      | `pageRange` / `bboxes` 已按逐页累积写入，前端分段高亮尚未接入     |
| 二进制资源引用                    | `assets` 字段保留，无写入方                                       |
| 阅读顺序切分统计                  | `orderCuts` 字段保留，从未赋值                                    |

## 十四、任务与落库边界

- **调用链**：`KnowledgeFileStructureController` → `StructureControlService`（上游产物校验 + 防重）→ `TaskTriggerSupport`（建 `QUEUED` 任务入队）→ 消费循环领取 → `StructureTaskRunner.run` → `AssemblerPipeline.assemble` → 产物落库 + 子步骤落库 + 终态回写。
- **落库目标**：产物行 `wb_knowledge_pipeline_product`（stage=`STRUCTURE`，`upstream_product_id` 指解析产物）、子步骤 `wb_knowledge_pipeline_step_log`、任务终态 `wb_knowledge_pipeline_task`。
- **终态回写互斥**：`finish`（`RUNNING → 终态`）与 `failQueued`（`QUEUED → FAILED`）都是条件更新，看门狗超时回写、执行器回写、入队失败回写三者只可能有一个生效。
- **滞留兜底**：入库未入队、或入队后没被消费的任务由 `TaskStartupCompensator` 兜住——启动补偿一次（补投创建时间早于 `compensateThreshold` 的 `QUEUED`）+ 低频周期扫描（默认开启、间隔 1 分钟，多实例用 Redis 锁防重）；同时把 `RUNNING` 超时的孤儿任务置 `FAILED`(`EXECUTOR_TIMEOUT`)。补投只在这条路径上发生，触发入口不做唤醒。
- **产物不可读**：详情接口按任务取产物，读不到时统计与结论都不陈述（返回空值与中性文案），不冒充真实值。
