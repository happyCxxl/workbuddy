# 接口交互

本环节用到三个接口，都由请求层统一处理：业务失败也是 HTTP 200 + `R.code`，提示由拦截器弹出，页面代码只看成功分支。通用口径（响应体形状、错误码分段、401 处理、`stage-content` 的分页参数）见 `../../README.md` 的「全局约定」章与 `../解析环节/02-接口交互.md`，本页只写切片特有的部分。

| 触发                                            | 前端调用链                                                               | 接口                                   | 请求                                                                                              | 响应 `data`                                       |
|-------------------------------------------------|--------------------------------------------------------------------------|----------------------------------------|---------------------------------------------------------------------------------------------------|---------------------------------------------------|
| 点「触发下一环节」并确认（下游）                | `PipelineStageView.onTriggerConfirm` → `api/pipeline.addStageTrigger`    | `POST /file-results/{id}/embed`        | `strategyVersionId`（可选）、`upstreamProductId`（必填，= 本切片产物）                            | `{pipelineTaskId, …}`                             |
| 从预处理卡片触发切片                            | 同上，`stage` 传 `CHUNK`                                                 | `POST /file-results/{id}/chunk`        | `strategyVersionId`（可选）、`upstreamProductId`（必填）                                          | `{fileResultId, pipelineTaskId, strategyVersion}` |
| 点「详情」（切片卡片）                          | `StageDetailDrawer` 的 watch → `api/pipeline.getStageDetail('CHUNK', …)` | `GET /file-results/{id}/chunk-detail`  | 查询参数 `taskId`（可选）                                                                         | `ChunkDetailVO`                                   |
| 点「详情」/ 翻页 / 切页签（兜底片与父片按需取） | `api/pipeline.getStageContent`                                           | `GET /file-results/{id}/stage-content` | 查询参数 `stage=CHUNK`、`taskId`、`current`、`size`、`contentType`/`fallback`/`hasParent`（可选） | 产物内容分页                                      |

`taskId` 一律传**被点的那张卡片**的任务 ID：不传会取该环节最新任务，抽屉是从某张卡打开的，不传就会显示成「最新一次」而不是「这一张」。

## `POST /file-results/{id}/chunk`

| 参数                | 必填 | 说明                                                                                                          |
|---------------------|------|---------------------------------------------------------------------------------------------------------------|
| `strategyVersionId` | 否   | 策略版本行 ID；不传则用知识库绑定的策略，两档都不命中 → 40438；指定了不存在 / 类型不符 / 已停用的版本 → 40433 |
| `upstreamProductId` | 是   | 指定上游 **PREPROCESS** 产物；未指定或传 0 → 40436（不接受"取该文件最新产物"这类回退）                        |

响应 `{fileResultId, pipelineTaskId, strategyVersion}`：异步接口，只登记任务，结果要轮询血缘；`strategyVersion` 是本次触发生效的策略版本串（如 `chunk-hybrid-v1`）。

**触发语义**（五个环节同一套：先校验存储一致性，再按执行键查重）：

- 执行键 = 文件结果 + `CHUNK` + 上游预处理产物 ID + 策略版本 ID；
- 查到（任何状态，含执行中）→ **40431**，消息「切片任务已创建（taskId=…，状态 …），请勿重复触发」，**不返回既有结果**；
- 查不到 → 新建一条 `QUEUED` 任务并入队（策略快照在触发时固定，执行只用快照）；
- 想再来一次：**换上游产物**或**换策略版本**（执行键不同即新链路），旧任务与旧产物保留；失败即终局，不允许原地重跑。

## `GET /file-results/{id}/chunk-detail`

查询参数 `taskId`（可选，缺省取该环节最新任务）。

| 字段                                                | 说明                                                                                                                                                                                                        |
|-----------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `fileResultId` / `taskId` / `stage` / `status`      | 文件结果、任务与状态（`PipelineTaskStatus` 枚举名）                                                                                                                                                         |
| `errorCode` / `errorMsg`                            | 失败时非空：任务级码（`CHUNK_EMPTY` / `CHUNK_FAILED`）                                                                                                                                                      |
| `startedAt` / `finishedAt`                          | 起止时间（ISO 串），未开始/未结束为空                                                                                                                                                                       |
| `artifactId` / `contentHash` / `capabilitySnapshot` | 产物引用与内容指纹；能力快照是策略快照的 JSON 文本，页面不消费                                                                                                                                              |
| `steps[]`                                           | 六步子步骤：`stepName` / `status` / `duration` / `warningCount` / `matchedCount` / `changedCount` / `error`                                                                                                 |
| `stageStats`                                        | 切片统计（读产物现算，见下）；**产物不可读时为 null**                                                                                                                                                       |
| `stageSummary`                                      | 结论一句话；取值规则见下                                                                                                                                                                                    |
| `summary`                                           | 汇总指标视图：`chunkCount` / `parentChunkCount` / `childChunkCount` / `totalChars` / `avgChars` / `typeCounts`；无集合时为 null                                                                             |
| `chunks[]`                                          | 切片列表（集合内顺序）：`chunkId` / `parentChunkId` / `content` / `contentType` / `titlePath` / `pageRange` / `tableRef` / `orderNo` / `charCount` / `tokenCount` / `sourceElementCount` / `fallbackReason` |

`chunks[]` 全量返回（**没有分页**），左栏按它排版；**`sourceElementCount` 与 `fallbackReason` 只有这个接口给**（两个字段只在切片产物里，`wb_knowledge_chunk` 无对应列）。

### `stageStats` 的键

计数一律是**数字**；`durationMs` 在起止时间缺失时为 null；策略参数缺失（快照不可解析）时不下发片长与兜底那几项。

| 键                      | 单位 | 口径                                                            |
|-------------------------|------|-----------------------------------------------------------------|
| `chunkCount`            | 片   | 切片总数（**含父片**，父片不产向量）                            |
| `sectionCount`          | 片   | 父片数（`contentType=SECTION`）                                 |
| `paragraphCount`        | 片   | 正文片数                                                        |
| `tableCount`            | 片   | 表格片数                                                        |
| `imageCount`            | 片   | 图片片数                                                        |
| `fallbackCount`         | 片   | 兜底片数（超长降级切分产出）                                    |
| `parentCount`           | 片   | **被挂子片的父片数**（按子片的 `parentChunkId` 反查集合内片）   |
| `orphanCount`           | 片   | 孤儿片数（无父片、也不是父片）                                  |
| `totalChars`            | 字符 | 全部片 content 长度合计                                         |
| `avgChars`              | 字符 | 平均片长（四舍五入取整）                                        |
| `maxChars`              | 字符 | 最长片                                                          |
| `overTargetMaxCount`    | 片   | 超过目标片长上限（策略 body 路 `targetMaxLen`，默认 800）的片数 |
| `minMergeLen`           | 字符 | 碎片合并阈值（流程层 `minMergeLen`，默认 300）                  |
| `underMinMergeCount`    | 片   | 欠长片数（子片里短于 `minMergeLen` 的片，父片不计）             |
| `overSoftMaxCount`      | 片   | 超过软上限（策略 body 路 `softMaxLen`，默认 1000）的片数        |
| `targetMaxLen`          | 字符 | 正文路的目标片长上限（策略参数）                                |
| `softMaxLen`            | 字符 | 正文路的软上限（策略参数）                                      |
| `fallbackLen`           | 字符 | 兜底切分的单片长度（策略 fallback 路 `len`，默认 500）          |
| `fallbackOverlap`       | 字符 | 兜底切分的重叠字符数（策略 fallback 路 `overlap`，默认 50）     |
| `routedElementCount`    | 个   | 进入切片的元素数 = 上游视图元素 − 跳过                          |
| `skippedElementCount`   | 个   | 跳过元素数（预处理剔除态与重复份）                              |
| `multiSourceChunkCount` | 片   | 来源元素多于 1 个的片数                                         |
| `avgSourceElementCount` | 个   | 平均来源元素数（四舍五入取整）                                  |
| `durationMs`            | 毫秒 | 本次运行耗时（起止时间相减）                                    |

`routedElementCount` / `skippedElementCount` / `targetMaxLen` / `softMaxLen` / `fallbackLen` / `fallbackOverlap` / `overTargetMaxCount` / `overSoftMaxCount` 这十项在对应来源取不到时**不下发该键**（上游预处理产物读不到、策略快照不可解析），页面按 `—` 展示。

### `stageSummary` 的取值规则

| 情形                      | 文案                                                                                            |
|---------------------------|-------------------------------------------------------------------------------------------------|
| 失败 / 已取消             | `errorMsg`，为空时「切片失败」                                                                  |
| 进行中 / 排队中           | null                                                                                            |
| 成功 / 部分成功，统计缺失 | **null**（产物不可读时不陈述结论）                                                              |
| 成功 / 部分成功，空集合   | 「没有产出任何切片（无可切内容）」                                                              |
| 成功 / 部分成功，无异常项 | 「全部为正文 / 表格 / 图片片，未走兜底」                                                        |
| 成功 / 部分成功，有异常项 | 「片数含 N 条不产向量的父片；K 片走了兜底切分；J 片无同节邻居；M 片超过软上限」（只陈述异常项） |

## `GET /file-results/{id}/stage-content?stage=CHUNK`

参数与分页口径与解析环节一致（见 `../解析环节/02-接口交互.md` 与 `03-接口逻辑.md`），本环节的差异：

- 新增三个过滤参数（都可选，只对 `CHUNK` 生效）：

| 参数          | 类型   | 说明                                                                                    |
|---------------|--------|-----------------------------------------------------------------------------------------|
| `contentType` | 字符串 | 内容类型（`ChunkContentType` 枚举名：`SECTION`/`PARAGRAPH`/`TABLE`/`IMAGE`/`FALLBACK`） |
| `fallback`    | 布尔   | `true` 只要兜底片、`false` 排除兜底片、不传不过滤                                       |
| `hasParent`   | 布尔   | `true` 只要子片、`false` 只要没有父片的片（父片与孤儿片）、不传不过滤                   |

- **过滤与分页都下推到 `wb_knowledge_chunk`**（`WHERE` + `LIMIT`/`COUNT`），不再把整个切片集合读进内存；`total` 与 `truncated` 都按**过滤后**的口径给（先过滤再分页）；
- `docPage` 对本环节无实际意义；
- `items[]` 的 `alignKey` 是**片 ID（`chunkId`）**、`type` 是内容类型、`display` 是片内容（`normalizedText` 口径）、`seq` 是集合内顺序号（`orderNo`）。

### `extra` 里的字段

| 键              | 类型   | 说明                                                  |
|-----------------|--------|-------------------------------------------------------|
| `chunkId`       | 字符串 | 片 ID（集合内唯一）                                   |
| `contentType`   | 字符串 | 内容类型（与 `type` 同值，前端也可直接从 `extra` 取） |
| `titlePath`     | 字符串 | 标题路径（` > ` 连接，层级上限由策略控制，默认 3 级） |
| `charCount`     | 数字   | 字符数                                                |
| `tokenCount`    | 数字   | Token 估算（`ceil(字符数 ÷ 1.5)`）                    |
| `orderNo`       | 数字   | 集合内顺序号（1 起；**换页定位按它算**）              |
| `parentChunkId` | 字符串 | 父片 ID（父片本身为空）                               |
| `pageRange`     | 字符串 | 页码范围（如 `1-3`，连续段压缩、多段逗号连接）        |
| `tableRef`      | 字符串 | 表格引用（组装环节的表元素 ID，表格片专用）           |

`extra` 里**没有** `sourceElementCount` 与 `fallbackReason`：这两个字段只在切片产物里，随 `chunk-detail` 的 `chunks[]` 下发。

## 本环节可能出现的失败

| code  | 触发场景                                                                           |
|-------|------------------------------------------------------------------------------------|
| 40001 | 环节不在白名单；`taskId` 不属于该文件该环节                                        |
| 40101 | 未认证（令牌缺失或已失效）                                                         |
| 40401 | 越权访问别人的文件结果（与「不存在」响应一致）                                     |
| 40431 | 触发时该执行键上已有切片任务（任何状态都拒）                                       |
| 40432 | 文件结果不存在；指定的上游产物不存在 / 不是 PREPROCESS 产物 / 不属于该文件结果     |
| 40433 | 指定的策略版本不存在、类型不符或未启用                                             |
| 40436 | 触发切片时没给 `upstreamProductId`（下游环节必填）                                 |
| 40438 | 既没显式指定策略、知识库侧也没有可用绑定（开关关闭 / 未绑定 / 绑定行缺失或已停用） |
| 40453 | 链的源文件所在数据源与当前启用的数据源不一致                                       |
| 40500 | 系统异常兜底                                                                       |

任务级错误码（落在 `errorCode`，不是接口返回码）：`CHUNK_EMPTY`（上游预处理视图缺失 / 读不到 / 反序列化失败 / 无可切内容）、`CHUNK_FAILED`（执行异常兜底）。

下游环节的相关失败：切片片长超过向量化模型的窗口允许字符数时，**向量化直接失败**（`EMBED_MODEL_INCOMPATIBLE`，40435）——调大 `targetMaxLen` / `softMaxLen` 或换模型前要留意这一条。

## 与后端不一致 / 需注意的地方

- **对齐键是片 ID**：`stage-content` 的 `alignKey` 与详情的 `chunkId` 同值（都是 `chunk-0001` 这种），左栏块与右栏行按它互相定位；`seq` / `orderNo` 只是展示用的顺序号。
- **`orderNo` 不是阅读序**：集合内顺序是"父片全部在前、子片随后、孤儿片最后"，左栏做过阅读序重排，**换页定位必须按 `orderNo` 算**，不能沿用左栏块下标。
- **`sourceElementCount` / `fallbackReason` 只在详情**：`stage-content` 的 `extra` 没有这两个键，右栏列表只用片号 / 类型 / 标题路径 / 字数。
- **父片溯源是子片并集**：父片的 `sourceElementIds` 为全部子片的来源元素并集（条数随章节大小无界），接口只给个数不展开列表。
- **片数含不产向量的父片**：`chunkCount` 是含父片的总数，向量化按 `includeParent=OFF` 跳过父片；统计条把「父片」单列一格。
- **「部分成功」是正常终态之一**：某个切片器对某个元素抛异常时其余片照常产出，异常进子步骤告警与结论，任务落 `PARTIAL_SUCCESS`（不是失败）。
