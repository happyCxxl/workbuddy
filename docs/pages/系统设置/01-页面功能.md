# 页面功能

页面用全局骨架（`.page` / `.page-head` / `.page-title` / `.page-desc`，页头副标题「管理你的系统通用设置」，见 `../../../web/src/styles/page-shell.css`），页头之下是卡片区（`.setting-body`：`flex: 1` + `overflow: auto`，卡片整体超出视口时滚这里），区里是**设置卡容器**（`.setting-cards`：`display: flex` + `flex-wrap: wrap` + `gap: 16px` + `align-content: flex-start`，一行放不下就换行）。卡片尺寸由容器上的两个变量统一给：`--setting-card-w: 275px`、`--setting-card-h: 305px`，`.setting-card` 的 `width` / `height` 直接取这两个变量并配 `box-sizing: border-box`（描边盒正好 275×305）——**所有设置卡片统一固定宽高**，不随卡内参数条数变化，新增卡片复用同一组变量。卡内信息面板撑满卡片剩余高度（`.setting-panel` 的 `flex: 1`）：参数多到面板装不下时在面板内滚（`.setting-panel-body` 的 `overflow: auto`），参数少时留白落在面板内部，不露在卡片底部。卡内从上到下两段——**存储源下拉**（含「启用」按钮）与「**当前启用**」信息块；确认弹窗是浮层，不占卡内位置。整页只有一类写动作：把某个存储源设为当前启用。

```
┌ 存储源 ──────────────────────────────────────────────────┐
│ 存储源  [ MinIO        ▾ ]  [启用]                       │
│ 当前启用  MinIO        已接入                            │
│  类型      MinIO                                         │
│  服务端点  http://localhost:9000                         │
│  访问密钥  minioadmin                                    │
│  私有密钥  minioadmin                                    │
│  文件桶    files                                         │
│  产物桶    artifacts                                     │
└──────────────────────────────────────────────────────────┘
```

## 权限与可见性

- **菜单与路由对所有登录用户可见**：侧栏一级叶子项「系统设置」与 `/settings` 路由都不带管理员标记；未登录访问 `/settings` 仍按全站口径跳 `/login`。
- **页内权限按卡片判**：本页是设置容器，每张卡自己判权限与数据来源；当前只有「存储源」一张卡，它按 `authStore.isAdmin` 渲染。
- **非管理员空态**：非管理员进页面只看到页标题与一行灰字空态「暂无你可以修改的设置」，卡片与卡内控件都不渲染，页面也不发起清单请求。
- **接口仍仅管理员**：三个接口的方法上都有 `@AdminOnly`，非管理员绕过界面直接发请求回 `40104`。菜单可见不等于接口放开，页面的可见性不改变接口的权限边界。

## 存储源下拉与「启用」

- 下拉是 `el-select`，只列 `status === 'ENABLED'` 的存储源（停用的不进候选），选项文案就是存储源**名称**（`SystemSettingView.sourceLabel` 只回 `name`，不拼类型码）；一个候选都没有时下拉禁用，占位文案「暂无启用的存储源」。
- 进页面时默认选中**当前启用**的那一项（清单里 `current === true` 的那一行）；清单里没有当前启用项时选中项为空。每次重新取清单时，选中项还在候选里就保持不变，已不在候选里就回落到当前启用项。
- 「启用」按钮的文案跟着选中项走：选中项就是当前启用项时读「**已启用**」并置灰（进页面默认选中的就是当前启用项，按钮初始即这个状态），选中别的存储源时读「启用」。置灰的另外两种情况：没有候选或选中项为空、预览与切换的请求进行中（`SystemSettingView.enableLabel` / `enableDisabled`）。可点时走下面「设为当前：两步走」。
- 换选下拉里的另一项只是**准备切过去**：信息块讲的是当前启用项，不随选中项变化，直到确认启用并重新取过清单。

## 「当前启用」信息块

信息块只讲**当前启用的那个存储源**，分块头与字段行两层：

| 位置   | 内容                                                                                                                                                                                                                                                                                                              |
|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 块头   | 「当前启用」+ 存储源名称（`name`）+ 状态四态文案（`SystemSettingView.sourceStateLabel`）                                                                                                                                                                                                                          |
| 类型   | 类型展示名（`storageTypeName`，如 `MinIO`），不带类型码                                                                                                                                                                                                                                                           |
| 参数行 | `params` 里的键与值**单列**逐行铺开（一行一个参数），键名换成中文展示名（`endpoint` 服务端点、`accessKey` 访问密钥、`secretKey` 私有密钥、`fileBucket` 文件桶、`artifactBucket` 产物桶、`rootDir` 根目录、`fileDir` 文件目录、`artifactDir` 产物目录），未知键显示原始键；参数值按等宽字体渲染（`.setting-mono`） |

`params` 返回该数据源的全部参数，`minio` 行含 `accessKey` 与 `secretKey` 的取值，页面上不做遮蔽；`local` 行只有三个目录类参数。

- 字段行多到面板装不下时，滚动落在面板内（`.setting-panel-body` 的 `overflow: auto`），卡片尺寸不变；面板高度由 `--setting-card-h` 定下的卡片固定高度减去卡头、启用入口与面板头后决定，不随字段行多少变化。
- 下拉里选了别的存储源时，这一块**仍显示当前启用的那个**；确认启用并重新取过清单之后才换成新源。
- 清单里没有当前启用项时，块内读「暂无启用的存储源」，读取期间读「加载中…」；没有当前启用项时应用本身启动失败，正常不会进入页面。

## 状态四态

判定顺序是先看 `registered`、再看 `probeOk`：

| 态       | 条件                                     | 呈现                |
|----------|------------------------------------------|---------------------|
| 已接入   | `registered = true` 且 `probeOk = true`  | 绿点 + 「已接入」   |
| 连接失败 | `registered = true` 且 `probeOk = false` | 黄点 + 「连接失败」 |
| 未测试   | `registered = true` 且 `probeOk = null`  | 灰点 + 「未测试」   |
| 未接入   | `registered = false`                     | 灰点 + 「未接入」   |

状态在页面上只出现一次，落在信息块块头上，讲的是当前启用的那个存储源；文案就是四态结论（`SystemSettingView.sourceStateLabel`），不带探测时间，「连接失败」这一态另有悬停提示给出完整的年月日与时分（`SystemSettingView.sourceStateTitle`）。`probeOk` 与 `probeAt` 读的是行上缓存的上一次探测结论与时间，由启动初始化与设为当前两处回写；页面自身不发起探测，探测时间只在「连接失败」的悬停提示里出现。

## 设为当前：两步走

1. **取影响面**：点「启用」调设置当前预览接口，这一步**不落库、不切换、不探活**，只做目标可用性校验与影响面统计。
2. **确认弹窗**：标题「启用 <存储源名称>」，正文首行是后端返回的 `message`，下面两块计数并排——「排队中 · 将跑不了」与「执行中 · 将跑不了」。按钮是「取消」与「确认启用」；点「取消」或点遮罩空白即结束，不发下一个接口；请求进行中两个按钮都禁用。
3. **启用**：确认后调设为当前接口，成功后重新取一次清单——下拉选中项与信息块一起跟着新值走，提示「已启用<存储源名称>」。任一步失败（目标已停用、参数缺项、探测不过、非管理员）时由拦截器弹出提示，页面状态保持不变。

## 页面不做的几件事

- **不新增、不编辑、不停用、不删除存储源**：数据源只能由 `workbuddy-biz/src/main/resources/config/workbuddy-file.yml` 的 seed 或库内 SQL 维护，`status = DISABLED` 的行在页面上没有任何操作入口。
- **没有连接测试**：页面不发起探测调用，状态读的是库里缓存的结论两列。
- **没有刷新按钮**：清单在进页面时取一次，启用成功后重新取一次，没有轮询。
- **密钥不做遮蔽**：`params` 返回全部参数，访问密钥与私有密钥作为普通参数行显示；服务端日志只打参数名与数据源名，不打参数值。
- **不改 `workbuddy-biz/src/main/resources/config/workbuddy-file.yml`**：页面的写动作只落 `wb_storage_source` 的 `is_current`（先清后置）与这次探测的结论两列，另留一条审计，配置文件始终不动。
