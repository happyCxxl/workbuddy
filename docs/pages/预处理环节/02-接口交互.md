# 接口交互

本环节用到三个接口，都由请求层统一处理：业务失败也是 HTTP 200 + `R.code`，提示由拦截器弹出，页面代码只看成功分支。通用口径（响应体形状、错误码分段、401 处理、`stage-content` 的分页参数）见 `../../README.md` 的「全局约定」章与 `../解析环节/02-接口交互.md`，本页只写预处理特有的部分。

| 触发                                        | 前端调用链                                                                    | 接口                                       | 请求                                                                       | 响应 `data`                                       |
|---------------------------------------------|-------------------------------------------------------------------------------|--------------------------------------------|----------------------------------------------------------------------------|---------------------------------------------------|
| 点「触发下一环节」并确认（下游）            | `PipelineStageView.onTriggerConfirm` → `api/pipeline.addStageTrigger`         | `POST /file-results/{id}/chunk`            | `strategyVersionId`（可选）、`upstreamProductId`（必填，= 本预处理产物）   | `{pipelineTaskId, …}`                             |
| 从组装卡片触发预处理                        | 同上，`stage` 传 `PREPROCESS`                                                 | `POST /file-results/{id}/preprocess`       | `strategyVersionId`（可选）、`upstreamProductId`（必填）                   | `{fileResultId, pipelineTaskId, strategyVersion}` |
| 点「详情」（预处理卡片）                    | `StageDetailDrawer` 的 watch → `api/pipeline.getStageDetail('PREPROCESS', …)` | `GET /file-results/{id}/preprocess-detail` | 查询参数 `taskId`（可选）                                                  | `PreprocessDetailVO`                              |
| 点「详情」/ 翻页 / 切页签（剔除内容按需取） | `api/pipeline.getStageContent`                                                | `GET /file-results/{id}/stage-content`     | 查询参数 `stage=PREPROCESS`、`taskId`、`current`、`size`、`status`（可选） | 产物内容分页                                      |

`taskId` 一律传**被点的那张卡片**的任务 ID：不传会取该环节最新任务，抽屉是从某张卡打开的，不传就会显示成「最新一次」而不是「这一张」。

## `POST /file-results/{id}/preprocess`

| 参数                | 必填 | 说明                                                                                                          |
|---------------------|------|---------------------------------------------------------------------------------------------------------------|
| `strategyVersionId` | 否   | 策略版本行 ID；不传则用知识库绑定的策略，两档都不命中 → 40438；指定了不存在 / 类型不符 / 已停用的版本 → 40433 |
| `upstreamProductId` | 是   | 指定上游 **STRUCTURE** 产物；未指定或传 0 → 40436（不接受"取该文件最新产物"这类回退）                         |

响应 `{fileResultId, pipelineTaskId, strategyVersion}`：异步接口，只登记任务，结果要轮询血缘；`strategyVersion` 是本次触发生效的策略版本串。

**触发语义**（五个环节同一套：先校验存储一致性，再按执行键查重）：

- 执行键 = 文件结果 + `PREPROCESS` + 上游组装产物 ID + 策略版本 ID；
- 查到（任何状态，含执行中）→ **40431**，消息「预处理任务已创建（taskId=…，状态 …），请勿重复触发」，**不返回既有结果**；
- 查不到 → 新建一条 `QUEUED` 任务并入队（策略快照在触发时固定，执行只用快照）；
- 想再来一次：**换上游产物**或**换策略版本**（执行键不同即新链路），旧任务与旧产物保留；失败即终局，不允许原地重跑。

## `GET /file-results/{id}/preprocess-detail`

查询参数 `taskId`（可选，缺省取该环节最新任务）。

| 字段                                                | 说明                                                                                                                                                                       |
|-----------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `fileResultId` / `taskId` / `stage` / `status`      | 文件结果、任务与状态（`PipelineTaskStatus` 枚举名）                                                                                                                        |
| `errorCode` / `errorMsg`                            | 失败时非空：任务级码（`PREPROCESS_EMPTY` / `PREPROCESS_FAILED`）                                                                                                           |
| `startedAt` / `finishedAt`                          | 起止时间（ISO 串），未开始/未结束为空                                                                                                                                      |
| `artifactId` / `contentHash` / `capabilitySnapshot` | 产物引用与内容指纹；能力快照是策略快照的 JSON 文本，页面不消费                                                                                                             |
| `steps[]`                                           | 九步子步骤：`stepName` / `status` / `duration` / `warningCount` / `matchedCount` / `changedCount` / `error`                                                                |
| `stageStats`                                        | 清洗统计（`PreprocessStatsVO`，读产物现算，见下）；**产物不可读时为 null**，null 字段不出现                                                                                |
| `stageSummary`                                      | 结论一句话；取值规则见下                                                                                                                                                   |
| `summary`                                           | 汇总指标视图：`elementCount` / `changedCount` / `excludedCount` / `repeatedCount` / `markedCount` / `chunkSkippedCount` / `fieldCount` / `statusCounts`；无产物时为 null   |
| `elements[]`                                        | 派生视图元素（**按阅读顺序全量，没有分页**）：`elementId` / `type` / `status` / `page` / `rawText` / `displayText` / `normalizedText` / `trace[]` / `fields[]` / `cells[]` |

`elements[]` 的 `trace` 只含**非 KEEP 条目**（未命中改写的元素没有轨迹）；`cells` 只在表格元素上有值。

### `stageStats` 的键

计数一律是**数字**；`durationMs` 在起止时间缺失时不出现；`statusCounts` / `fieldTypeCounts` 是「键 → 计数」的对象。

| 键                    | 单位 | 口径                                                                         |
|-----------------------|------|------------------------------------------------------------------------------|
| `elementCount`        | 个   | 视图元素总数                                                                 |
| `retainedCount`       | 个   | 保留元素数 = 总数 − 不进切片数（这些元素进检索内容流）                       |
| `retentionPercent`    | %    | 保留占比（四舍五入取整；无元素记 0）                                         |
| `excludedCount`       | 个   | 剔除态元素数（`EXCLUDED_*` 与 `BACKUP_SKIPPED`，**不含重复份**）             |
| `repeatedCount`       | 个   | 重复份元素数（剔除档 `REPEATED`；重复档选标记时计入 `markedCount`）          |
| `chunkSkippedCount`   | 个   | 不进切片的元素数 = `excludedCount` + `repeatedCount`                         |
| `markedCount`         | 个   | 仅标记元素数（页眉 / 页脚 / 目录 / 噪声 / 重复份：标注后**仍进检索内容流**） |
| `fieldCount`          | 个   | 标准化字段总数（金额 / 日期 / 面积 / 证书号）                                |
| `changedCount`        | 个   | 文本改写元素数：`normalizedText` 非空且与 `displayText` 不同                 |
| `encodingCount`       | 个   | 编码规范化命中的元素数（轨迹规则名前缀 `encoding-`）                         |
| `tidyCount`           | 个   | 文本整理命中的元素数（轨迹规则名前缀 `text-tidy`）                           |
| `statusCounts`        | 对象 | 按处置状态分布（状态名 → 元素数；状态缺失归 `UNKNOWN`）                      |
| `fieldTypeCounts`     | 对象 | 按字段类型分布（字段类型名 → 字段数；类型缺失归 `UNKNOWN`）                  |
| `pageFrom` / `pageTo` | 页   | 受影响元素所在页的始末（被处置或有改写的元素；一条都取不到时**不下发该键**） |
| `durationMs`          | 毫秒 | 本次运行耗时（起止时间相减，缺失时不出现）                                   |

### `stageSummary` 的取值规则

| 情形                      | 文案                                                                    |
|---------------------------|-------------------------------------------------------------------------|
| 失败 / 已取消             | `errorMsg`，为空时「预处理失败」                                        |
| 进行中 / 排队中           | null                                                                    |
| 成功 / 部分成功，统计缺失 | **null**（产物不可读时不陈述结论）                                      |
| 成功 / 部分成功，空视图   | 「无任何可处理的元素（空视图）」                                        |
| 成功 / 部分成功，无异常项 | 「未剔除内容，全部进入切片」                                            |
| 成功 / 部分成功，有异常项 | 「N 项仅标记、仍在检索内容流；M 项已剔除出检索内容流；重复份 K 已剔除」 |

## `GET /file-results/{id}/stage-content?stage=PREPROCESS`

参数与分页口径与解析环节一致（见 `../解析环节/02-接口交互.md` 与 `03-接口逻辑.md`），本环节的差异：

- 新增 `status`（可选）：逗号分隔的处置状态，只回这些状态的元素；**先过滤再分页**，`total` 与 `truncated` 都按过滤后的口径给。前端「剔除内容」页签传的就是"不进切片"的那批状态（`EXCLUDED_*` + `BACKUP_SKIPPED` + `REPEATED`）；
- `docPage` 对本环节无实际意义（左栏没有按页预览）；
- `items[]` 的 `alignKey` 是产物元素 ID、`status` 是处置状态、`display` 是展示文本、`normalized` 是检索文本（剔除态为 null）。

### `extra` 里的字段

`extra` 的类型是 `StageContentExtraVO`（未用到的字段为 null 且不输出），本环节用到的：

| 键                 | 类型       | 说明                                                                                                                                          |
|--------------------|------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| `rawText`          | 字符串     | 原文（永久保留、从不修改）；与展示 / 检索文本构成三层对照                                                                                     |
| `marks`            | 字符串数组 | 源元素标记（识别环节写入，如 `TOC_LINE` / `REPEATED_SEGMENT`）                                                                                |
| `trace`            | JSON 串    | 处理轨迹（只含非 KEEP 条目）：`rule` / `field` / `action` / `before` / `after` / `evidence`；**只对被处理过的元素下发**，未命中的元素没有该键 |
| `normalizedFields` | JSON 串    | 标准化字段列表（`field` / `value` / `unit` / `rule`）                                                                                         |
| `cells`            | JSON 串    | 表格单元格（`cellId` / `text` / `row` / `col` / `isHeader` / `normalizedText`）                                                               |
| `page`             | 数字       | 元素所属文档页（Word 段落没有页概念）                                                                                                         |

## 本环节可能出现的失败

| code  | 触发场景                                                                           |
|-------|------------------------------------------------------------------------------------|
| 40001 | 环节不在白名单；`taskId` 不属于该文件该环节                                        |
| 40101 | 未认证（令牌缺失或已失效）                                                         |
| 40401 | 越权访问别人的文件结果（与「不存在」响应一致）                                     |
| 40431 | 触发时该执行键上已有预处理任务（任何状态都拒）                                     |
| 40432 | 文件结果不存在；指定的上游产物不存在 / 不是 STRUCTURE 产物 / 不属于该文件结果      |
| 40433 | 指定的策略版本不存在、类型不符或未启用                                             |
| 40436 | 触发预处理时没给 `upstreamProductId`（下游环节必填）                               |
| 40438 | 既没显式指定策略、知识库侧也没有可用绑定（开关关闭 / 未绑定 / 绑定行缺失或已停用） |
| 40453 | 链的源文件所在数据源与当前启用的数据源不一致                                       |
| 40500 | 系统异常兜底                                                                       |

任务级错误码（落在 `errorCode`，不是接口返回码）：`PREPROCESS_EMPTY`（上游统一结构无任何可处理元素，或上游产物缺失 / 读不到 / 反序列化失败）、`PREPROCESS_FAILED`（执行异常兜底）。

## 与后端不一致 / 需注意的地方

- **`stats` 与 `stageSummary` 分工**：节点与详情都从**同一份产物**现算，`stageStats` 给数字、`stageSummary` 给一句话；产物读不到时两者都为 null（此时页面不陈述结论）。
- **「仅标记」仍进检索内容流**：默认策略下页眉页脚与目录只是被标注，`normalizedText` 照常参与切片；把它们当成"已剔除"会低估下游内容量。
- **三层文本各有用处**：`rawText` 永远可回溯原文、`displayText` 供阅读（只整理空白换行与明显乱码）、`normalizedText` 供检索（字符级规范化 + 字段标准化）；**剔除态的 `normalizedText` 为 null**，其单元格的 `normalizedText` 也一并置 null，但**单元格 `text` 仍是展示文本**（展示视图完整保留）。
- **`summary` 与 `stageStats` 是两套字段**：`summary` 是旧展示口径的汇总指标，八格统计条取的是 `stageStats`（例如「剔除」不含重复份、`chunkSkippedCount` 才是"不进切片"总数）。
- **「部分成功」是正常终态之一**：某条规则对某个元素抛异常时该元素照常产出，异常进子步骤告警与结论，任务落 `PARTIAL_SUCCESS`（不是失败）。
- **`elements` 没有分页**：详情一次回全量视图元素（左栏文档按需渲染，右栏列表走 `stage-content` 分页）。
