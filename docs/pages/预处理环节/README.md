# 预处理环节

执行链页（`/knowledge/:id/stages`）上的**预处理**环节：单张清洗卡片（清洗体检清单）、触发预处理（按策略两档解析版本：显式指定 → 知识库绑定）、以及「详情」抽屉里的清洗后正文与清洗结果 / 剔除内容 / 字段 / 过程 / 告警。

| 项           | 值                                                                                                                                                                                                            |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 路由         | `/knowledge/:id/stages`（与其余环节共用同一路由，按执行链节点区分）                                                                                                                                      |
| 入口         | 知识库列表 → 某库的「切片阶段（执行链）」→ 预处理环节卡片                                                                                                                                                     |
| 前端视图     | `../../../web/src/views/knowledge-base/PipelineStageView.vue`（页面）                                                                                                                                         |
| 前端组件     | `../../../web/src/components/pipeline/ChainNode.vue`（卡片）、`../../../web/src/components/pipeline/StageDetailDrawer.vue`（抽屉，各环节共用）、`../../../web/src/components/pipeline/ChainGraph.vue`（画布） |
| 环节展示口径 | `../../../web/src/types/pipeline-stage-view.ts`（卡片指标 / 体检清单 / 页签 / 左栏形态的配置表，按环节取值）                                                                                                  |
| 前端接口层   | `../../../web/src/api/pipeline.ts`                                                                                                                                                                            |
| 后端         | `KnowledgeFilePreprocessController`（触发预处理 / 预处理详情）、`KnowledgeFileStageController`（各环节共用的产物内容）、`PreprocessTaskRunner`（执行器）、`PreprocessPipeline`（九步管线）                    |
| 涉及接口     | `POST /file-results/{id}/preprocess`、`GET /file-results/{id}/preprocess-detail`、`GET /file-results/{id}/stage-content?stage=PREPROCESS`（支持 `status` 过滤）                                               |

卡片与抽屉是**各环节共用**的一套结构（`ChainNode` + `StageDetailDrawer`），差异全部由 `../../../web/src/types/pipeline-stage-view.ts` 的环节配置给出。抽屉的四个固定分区、分隔条、底部下载、`stage-content` 的分页参数与解析环节共用同一套实现，本目录不复述，见 `../解析环节/01-页面功能.md` 与 `../解析环节/02-接口交互.md`。原文（统一文档）在预处理环节**只读零改动**：处置只落在派生视图副本上。

## 待定项

- **产物里没有「视图 schema」字段**：卡片身份行只能显示策略版本，没有可展示的视图版本号；是否在视图产物契约里补一个版本号尚未决定。
- **`pageFrom` / `pageTo` 已算但未展示**：统计里的"受影响页范围"已在读取侧现算，页面还没有位置展示它，是否接进统计条或页签尚未决定。
- **剔除率没有警示阈值**：目前只报"剔除了多少"，没有"剔除率偏高"的判据；阈值取值与是否要警示尚未决定。
- **「下游切片少掉多少」只能给元素数**：能给的只有"不进切片的元素数"，切片条数取决于切片策略（整表 / 行组等），当前口径给不了，是否要按策略估算尚未决定。
- **`preprocess-detail` 一次回全量元素、没有分页**：大文档的详情响应体偏大；是否改成分页（左栏文档改按需取数）尚未决定。
- **默认策略下「仅标记」是大头**：页眉页脚与目录默认只标注、仍进检索，卡片把它与"剔除"并列展示；是否要给更强的提示（例如把"仍在检索"说得更显眼）尚未决定。
- **视图不带标题层级**：派生视图元素没有 `level`，清洗后的正文标题只能按单档呈现（层级由正文里的编号表达）；是否在视图契约里补层级尚未决定。
