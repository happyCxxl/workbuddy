# 自测清单

改完壳（菜单、返回、折叠、退出、账号区入口）后手工过一遍。前置条件：中间件已起、后端已启动、前端 dev server 已启动，并各准备一个管理员与一个普通用户账号。

## 菜单与角色

- [ ] 管理员登录 → 侧栏一级菜单 6 项（首页 / 知识库 / 用户管理 / 模型管理 / 系统设置 / 个人中心），二级 3 项：「知识库」下 2 项（知识库管理 / 策略管理）、「模型管理」下 1 项（模型清单）
- [ ] 普通用户登录 → 一级菜单 5 项（没有「用户管理」，其余五项与管理员相同）
- [ ] 侧栏主导航末项是「个人中心」，点击进入 `/profile`
- [ ] 侧栏底部与顶栏头像两处的下拉只留「退出登录」
- [ ] 普通用户直接在地址栏输入 `/user` → 被守卫送回 `/home`
- [ ] 进入 `/knowledge/<id>/stages` → 二级「知识库管理」保持点亮、组标题「知识库」转亮且箭头转主色；在 `/home` 时只有「首页」亮
- [ ] 点组标题「知识库」→ 二级项收起（标题自身不跳转）；再点一次展开
- [ ] 进入 `/knowledge/strategy` → 组自动展开且二级「策略管理」点亮；此时点组标题收起，再切到 `/knowledge/manager` → 组重新展开
- [ ] 进入 `/model/manager` → 「模型管理」组自动展开、二级「模型清单」点亮
- [ ] 侧栏品牌行为「logo + 工作台 / AI 工作台」，点整行回 `/home`；浏览器页签标题为「页面名 · AI 工作台」
- [ ] 菜单文字规格一致：一级项、二级项、收起态面板内的项同字号（14px）同字体，组标题不比其他项大
- [ ] 三个二级项都带图标，尺寸与一级项图标相同（16px），只多一层左缩进（落在竖向导轨右侧）

## 折叠

- [ ] 点侧栏右边界的光缝 → 收起为图标模式，动画过程中图标不出现横向跳动
- [ ] 收起后刷新页面 → 仍是收起态；再展开后刷新 → 仍是展开态
- [ ] 收起态下悬停菜单项 → 有气泡提示菜单名
- [ ] 收起态下悬停组标题「知识库」的图标 → 右侧浮出二级面板（顶部带组名），当前项在其中高亮；鼠标移开面板收起
- [ ] 收起态下的组标题图标：当前路由在组内时带底色与左侧渐变竖条，箭头不显示
- [ ] 组标题右侧有开合箭头（展开朝上、收起朝下），收起态下箭头不显示
- [ ] 收起态下用 Tab 键聚焦组标题 → 浮出面板同样出现，可继续 Tab 进面板里的二级项

## 返回按钮

- [ ] 知识库列表 → 返回「首页」
- [ ] 切片阶段 / 索引与发布 / 检索评测 → 都返回「知识库」
- [ ] 策略管理 / 用户管理 / 系统设置 → 返回「首页」
- [ ] 首页 → 顶栏左侧为空（不渲染返回按钮）

## 退出登录

- [ ] 点「退出登录」→ 提示「已退出登录」并回到 `/login`
- [ ] 退出后按浏览器后退 → 回不到受保护页（令牌已清，守卫拦回登录页）

## 个人中心

入口与账号相关功能的自测项在 `../个人中心/04-自测清单.md`。

- [ ] 设置头像后，侧栏底部与顶栏两处头像同时变成图片；移除后回落姓名首字

- [ ] 悬停菜单项与用户块 → 两个悬浮框的左边距、宽度、圆角、底色**完全一致**
- [ ] 悬停左下角用户块 → 悬浮框**不出侧栏**（不压到内容区分隔线）
- [ ] 折叠 / 展开侧栏 → 头像与导航图标始终在同一竖中线，且动画期间头像**不横向滑动**
- [ ] 折叠态下头像**完整可见**（右侧不被裁切）
- [ ] 用超长姓名登录 → 侧栏姓名以省略号收尾，用户块不撑破侧栏

## 内容区

- [ ] 任意子页面内容超高时，滚动发生在页面内部，壳不出现第二条滚动条
