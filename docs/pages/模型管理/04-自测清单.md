# 自测清单

改完本页（页面、接口、后端逻辑任一）后手工过一遍。前置条件：中间件已起、后端与前端 dev server 已启动；准备一个管理员账号与一个普通用户账号；`knowledge.model.vendors` 里至少配一个厂商（`api-key` 用环境变量注入、`auth-type: BEARER`），`wb_model` 至少有一行 `status = 'ENABLED'`。

## 入口与权限

- [ ] 管理员登录后，侧栏一级分组「模型管理」下有两个二级项「模型清单」「用量与成本」；点「模型清单」进入 `/model/manager`，页头副标题是「维护可用模型与价格限额，以及启用状态」
- [ ] 普通用户登录后，侧栏**同样出现**「模型管理」及其两个二级项，直接手输 `/model/manager` 与 `/model/usage` 也能进（页面与接口对所有登录用户开放，不是管理员专项）
- [ ] 普通用户绕过界面调六条接口中的任一条（`GET /model/models`、`POST /model/models`、`PUT /model/models/{id}`、`PATCH /model/models/{id}/status`、`GET /model/usage/summary`、`GET /model/usage/calls`）→ 都回 200 + `R.code = 0`
- [ ] 未登录直接调任一条 → 回 `40101`
- [ ] 两条已下线的路径（厂商清单接口与连通性测试接口，路径见路由测试）→ 都回 `404`
- [ ] 两页页头的返回按钮都回到「首页」

## 菜单与模型清单

- [ ] 在 `/model/usage` 时，侧栏只有一个二级项点亮（「用量与成本」），父项「模型管理」转亮；在 `/model/manager` 时点亮「模型清单」
- [ ] 收起侧栏后，切到本分组时浮出面板列出两个二级项
- [ ] 两页各自记住自己的筛选与表格数据，来回切换不互相重置
- [ ] 表头八列是厂商 / 模型 / 能力 / 长度（输入 / 输出 / 上下文）/ 价格（缓存未命中 / 命中 / 输出）/ 限额（RPM / TPM）/ 状态 / 操作，八列等宽
- [ ] 厂商列第一行是展示名、第二行是灰色等宽的厂商码；`dashscope` 一行读「阿里百炼」
- [ ] 模型列读厂商侧模型名（如 `qwen-max`），等宽
- [ ] 一个多能力模型（如 `OCR,LAYOUT,TABLE_STRUCTURE`）在同一行的能力列显示三枚标签
- [ ] 长度列读「最大输入 / 最大输出 / 上下文长度」三个值，走 K / M 后缀：`1000000` 读 `1M`、`384000` 读 `384K`、`131072` 照实读 `131072`；任一为空读 `—`
- [ ] 价格列读「缓存未命中 / 缓存命中 / 输出」三个单价，末尾带币种与「百万 token」；三列都空的行读 `—`
- [ ] 限额列读「RPM / TPM」，某项为空读 `—`
- [ ] 能力下拉选 `CHAT` 后只剩含 `CHAT` 的行；选一个没有任何行具备的能力时表格空态读「暂无模型」
- [ ] 状态下拉选「停用」只剩 `DISABLED` 的行；选「启用」只剩 `ENABLED` 的行
- [ ] 关键字输入模型名的一部分能命中（如 `qwen`）；输入不存在的串空态读「暂无模型」
- [ ] 点「重置」后三个条件都清空并重新查询；点「查询」按当前条件重查；刷新按钮请求期间禁用并旋转

- [ ] 页脚读「共 N 条」
