# 自测清单

改完本页（页面、接口、后端逻辑任一）后手工过一遍。前置条件：中间件已起、后端与前端 dev server 已启动，并准备一个普通用户账号与一个管理员账号。

## 入口与路由

- [ ] 侧栏主导航末项是「个人中心」，点击进入 `/profile`
- [ ] 点「个人中心」→ 进入 `/profile`，顶栏左侧出现返回按钮，标题为「返回首页」
- [ ] 点返回 → 回到 `/home`
- [ ] 侧栏底部与顶栏头像两处的下拉只留「退出登录」（个人中心在主导航里）

## 账号信息（只读）

- [ ] 用户名、角色、状态与库中一致（管理员显示「管理员」，停用账号显示「停用」）
- [ ] 创建 / 更新时间显示为格式化时间（不是 ISO 原串）；取不到时显示 `-`
- [ ] 页面没有任何可编辑用户名 / 角色 / 状态的控件

## 基本信息

- [ ] 进页面时三个字段是服务端最新值（改完资料换设备登录再看，仍是新值）
- [ ] 保存 → 提示「保存成功」，布局壳侧栏与顶栏的姓名**立即**更新，不需要重新登录
- [ ] 把邮箱清空保存 → 库中该列为 `null`（不是空串、也不是空白串）
- [ ] 真实姓名清空、邮箱填非法格式 → 前端拦住，不发请求
- [ ] 前端拦不住时（例如直接调接口）后端仍返回 `40001`
- [ ] 保存后不换令牌：当前会话继续可用，其他设备也不受影响

## 修改密码

- [ ] 当前密码填错 → `40110`
- [ ] 新密码与当前密码相同 → `40001`（消息「新密码不能与当前密码相同」）
- [ ] 新密码 7 位、两次输入不一致 → 前端拦住
- [ ] 新密码 11 位 → 也被前端拦住（上限 10 位）
- [ ] 改密成功 → 提示「密码已修改，其他设备需用新密码重新登录」，三个输入被清空，**当前会话不掉线**
- [ ] 改密后立刻做一次保存资料 → 仍成功（说明本地令牌已换成补签的那张）
- [ ] 改密后用旧密码重新登录 → `40103`（旧令牌与旧密码都已失效）
- [ ] 库中核对：`wb_user.token_version` 已 +1；审计表新增一条 `USER_PASSWORD_CHANGE` 且前后摘要为空

## 头像

- [ ] 点「更换头像」选一张 PNG / JPG / WebP → 横幅与壳两处**同时**变图，刷新后仍在
- [ ] 把文本文件改名成 `.png` 再传 → `40001`（魔数校验拦下）
- [ ] 传一张大于 2MB 的图 → `40001`
- [ ] 点「移除」→ 横幅与壳回落姓名首字
- [ ] 未登录直接调 `POST /user/avatar` → `40101`
- [ ] 地址栏直开 `/user/avatar/{别人的id}` → 能看到图（免登录）；`/user/avatar/999` → `404`
- [ ] 上传后在库里核对 `wb_user`：`avatar` / `avatar_storage_source_id` / `avatar_storage_type` / `avatar_bucket` 四列**一起写入**，数据源 ID 与类型码取自当前启用的那一行，桶名与对象实际所在桶一致（本地数据源是存储根下的一级子目录）
- [ ] 点「移除」后再核对同样四列：**一起变 `null`**
- [ ] 切到另一个数据源后刷新页面 → 旧头像仍能显示（读取按行里的数据源 ID 定位后端，与当前启用无关）；再上传一张 → 四列改指新的数据源
- [ ] 存储目录出现 `files/avatar/{userId}/{随机段}.{扩展名}`（本地数据源落在它那一行的存储根目录下；MinIO 数据源在 `files` 桶里）
