# 页面功能

## 给谁用

所有登录用户。首页是**只读概览**：没有任何写操作；资产带与「最近提交」**都只覆盖本人可见的范围**（见下），不同账号看到的数字与表格内容不同。

## 两块内容

页面自上而下两块，装在同一套页面骨架里（`.page-head` → `.page-assets` → `.page-panel`）。

### 1. 资产速览（`.page-assets`，三格并列）

| 格       | 主数                                   | 副文案                                  |
|----------|----------------------------------------|-----------------------------------------|
| 知识库   | 可见范围内知识库总数（含已停用）       | `启用 N`                                |
| 文档     | 可见库下的已建档文档数                 | `已建档文档`                            |
| 可用策略 | 启用中的策略版本数（四类合计，全平台） | `预处理 N · 切片 N · 向量化 N · 检索 N` |

三处口径如下，改文案前先看 `03-接口逻辑.md`：

- **知识库与文档按可见范围收口**：普通用户只统计自己创建的库（及其下文档），管理员统计全部，与[知识库列表](../知识库列表/README.md)页同一口径："资产"是"我的资产"，不是"平台资产"；
- 「文档」的主数是 `wb_file_result` 行数，**不含文件校验失败的提交**（校验失败只写 `wb_submit_log(FAIL)`，不建结果），副文案写「已建档文档」而不是「提交总数」；
- 「可用策略」**只数启用中的版本**（`status = ACTIVE`）：停用的版本仍留在策略管理页可查，但不能被绑定使用。策略是平台级资产，**不按知识库归属过滤**。

索引版本数**不在首页展示**（知识库卡片上已有「索引版本」一格），后端也不计算这两个计数。

### 2. 最近提交（唯一的 `.page-panel`）

- 工具栏：只有区块标题（口径看下面的「结果」列与 `03-接口逻辑.md`）；
- 数据范围：**当前登录用户**的提交记录，新→旧（后端按安全上下文过滤，前端不传提交人）；
- 五列，顺序固定：

| 列       | 内容                                                                       |
|----------|----------------------------------------------------------------------------|
| 文件名   | 取不到文件名时显示「（文件名不可得）」；过长单行截断，完整名在 `title` 里  |
| 文件类型 | 后端由来源文件的 MIME 换算（`PDF` / `DOCX` / `XLSX` …）；取不到显示 `—`    |
| 知识库   | 库名；库已删除时回落成「知识库 {ID}」                                      |
| 结果     | `通过` 绿徽标 / `未通过` 红徽标，未通过时右侧跟失败原因中文                |
| 提交时间 | `yyyy-MM-dd HH:mm`（**带年份**：这是本人提交历史的唯一入口，跨年不会歧义） |

- **列宽与对齐**：五列等宽（同一 `min-width`），表头与单元格一起居中；口径见[前端开发规范](../../../.agent/standards/frontend/前端开发规范.md) §6.7 / §6.8 / §6.9，机器拦截在 `pnpm lint` 的 `check-table`。
- 面板脚：左侧「共 N 条」，右侧**分页**（上一页 / 当前页 / 下一页，只显示当前页）。

## 分页与容器高度

- **每页固定 10 条**，页长不随窗口高度变化，翻页逐页推进（分页只显示当前页，没有页码清单）；
- **容器高度与本页记录数无关**：表体是 `flex: 1` + `min-height: 0`，高度由面板（即页面剩余高度）决定 —— 末页只有两三条时容器不会塌下去，翻页不会跳动；
- 窗口太矮时是**表格内部滚动**，页面本身不会被裁切（`.layout-content` 是 `overflow: hidden`，页面整体不滚动）。

## 加载态与空态

- 列表用 `v-loading` 遮罩，**不用 `v-if` 换掉表格**：那样每次翻页都会销毁重建整张表格，页面会闪一下；空态走 `#empty` 插槽，表格始终挂载；
- 资产带在数据回来之前显示 `—` 占位（不是 `0`），避免先闪一个 0 再跳成真实值；
- 接口失败由请求层统一提示，页面只保留占位符（根文档「全局约定·三」）。

## 交互一览

| 操作                  | 结果                            |
|-----------------------|---------------------------------|
| 进入页面              | 并行拉资产速览与第一页提交记录  |
| 点上一页 / 下一页     | 只重拉提交记录，资产速览不动    |
| 悬浮文件名 / 知识库名 | 由 `title` 显示被截断的完整内容 |

页面上没有任何写操作，也没有「刷新」按钮。
