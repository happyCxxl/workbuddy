# 自测清单

改完首页后手工验这些点。带「后端」标记的项要重启后端；其余只需刷新页面（改完后端记得重启，前端改动热更新即可）。

## 一、可见范围

| 检查项                            | 期望结果                                                                       |
|-----------------------------------|--------------------------------------------------------------------------------|
| 用账号 A 登录，看提交表           | 只出现 A 自己提交的文件                                                        |
| 换账号 B 登录（B 从未提交过）     | 表格为空，显示「还没有提交记录」；**看不到 A 的记录**                          |
| 用账号 B 提交一个文件后再看       | 只有 B 的新记录出现，A 的历史记录仍然不在                                      |
| 浏览器直接请求接口（带 A 的令牌） | `GET /home/recent-submits` 返回的全是 A 的记录；**请求里没有任何"提交人"参数** |
| 表头                              | **没有**「提交人」列                                                           |

## 二、列与内容

| 检查项               | 期望结果                                                          |
|----------------------|-------------------------------------------------------------------|
| 列顺序               | 文件名 → 文件类型 → 知识库 → 结果 → 提交时间                      |
| 文件类型（校验通过） | 显示 `PDF` / `DOCX` / `XLSX` 这类枚举名，与实际上传的文件格式一致 |
| 文件类型（校验失败） | 显示 `—`（失败行不建来源文件，取不到 MIME）                       |
| 结果列               | `通过` 绿徽标 / `未通过` 红徽标；未通过时右侧跟失败原因中文       |
| 文件名过长           | 单行截断成省略号，鼠标悬浮显示完整文件名（`title`）               |
| 知识库已删除的行     | 知识库列显示「知识库 {ID}」，不空着                               |
| 提交时间             | `yyyy-MM-dd HH:mm`（**带年份**），定长显示；列宽随窗口平均伸缩    |
| 列宽                 | 五列等宽（同一 `min-width`），窗口变宽时五列一起变宽              |
| 表头                 | 表头与单元格同为居中（表头压在列内容中位线上）                    |
| 空态                 | 没有记录时表格仍挂载，显示「还没有提交记录」；资产带仍正常显示    |

## 三、分页与容器高度

| 检查项                   | 期望结果                                                                                  |
|--------------------------|-------------------------------------------------------------------------------------------|
| 首屏                     | 每页正好 10 条                                                                            |
| 分页                     | 面板脚右侧只有上一页 / 当前页 / 下一页三格（**不列全部页码**）；左侧「共 N 条」随数据变化 |
| 末页（不足 10 条）       | **表格容器高度不变**，不会塌下去；面板脚不往上跳                                          |
| 翻页                     | 只有表格区域变化，资产带与页面其它部分不重排、不闪                                        |
| 把窗口拖矮（小于 10 行） | 表格**内部**出现滚动条，页面本身不出现整页滚动条、内容也不被裁掉                          |
| 拖动窗口高度             | **不触发任何接口请求**（Network 面板只看 `/home` 可确认）                                 |

## 四、资产速览的口径

| 检查项                               | 期望结果                                                                                        |
|--------------------------------------|-------------------------------------------------------------------------------------------------|
| 「文档」格副文案                     | 显示「已建档文档」，**不是**「提交总数」                                                        |
| 「文档」数与知识库列表页的「文档数」 | 两个数字相等（同源：`wb_file_result` 行数，同可见范围）                                         |
| 可见范围（普通用户）                 | 「知识库」只数自己创建的库；**名下一个库都没有的账号看到 0**，而不是全平台的数字                |
| 可见范围（管理员）                   | 「知识库」数的是全平台的库（含 `user_id` 为空的早期种子库）                                     |
| 可见范围（策略格对照）               | 「可用策略」**不随账号变**（策略是平台级资产，四类计数人人相同）                                |
| 后端：提交一条校验失败的文件         | 提交表总数 +1，而「文档」数**不变**                                                             |
| 后端：停用一个策略版本               | `wb_knowledge_pipeline_strategy_version.status` 改为 `INACTIVE` → 「可用策略」与对应细分数各 −1 |
| 索引版本计数                         | 页面上**不应出现**索引版本相关的数字（接口响应里没有）                                          |
| 数据未加载完                         | 三个数字先显示 `—`，不闪 `0`                                                                    |

## 五、权限与异常

| 检查项                           | 期望结果                                                 |
|----------------------------------|----------------------------------------------------------|
| 普通用户（非管理员）登录后进首页 | 正常显示资产带与自己的提交（菜单里没有用户管理）         |
| 未登录直接访问 `/home`           | 路由守卫跳 `/login?redirect=/home`；登录后回到首页       |
| 令牌失效时停在首页               | 刷新后按 40101 处理：清令牌并回登录页，不卡在空白页      |
| 页面上                           | **没有**「行为记录」面板、没有任何审计动作相关的列或入口 |

## 六、回归（连带影响）

| 检查项       | 期望结果                                                                             |
|--------------|--------------------------------------------------------------------------------------|
| 前端检查     | `cd web && pnpm lint` 八项全过（含 `check-spec` 样式类扫描、`check-table` 表格口径） |

| 策略管理页   | 停用 / 启用版本的功能不受影响（首页只读 `status`，不写）                             |
