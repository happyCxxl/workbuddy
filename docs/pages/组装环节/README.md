# 组装环节

执行链页（`/knowledge/:id/stages`）上的**组装**环节：单张组装卡片（结构体检清单）、触发组装、以及「详情」抽屉里的组装产物文档与结构树 / 元素 / 告警 / 过程。

| 项           | 值                                                                                                                                                                                                            |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 路由         | `/knowledge/:id/stages`（与其余环节共用同一路由，按执行链节点区分）                                                                                                                                      |
| 入口         | 知识库列表 → 某库的「切片阶段（执行链）」→ 组装环节卡片                                                                                                                                                       |
| 前端视图     | `../../../web/src/views/knowledge-base/PipelineStageView.vue`（页面）                                                                                                                                         |
| 前端组件     | `../../../web/src/components/pipeline/ChainNode.vue`（卡片）、`../../../web/src/components/pipeline/StageDetailDrawer.vue`（抽屉，各环节共用）、`../../../web/src/components/pipeline/ChainGraph.vue`（画布） |
| 环节展示口径 | `../../../web/src/types/pipeline-stage-view.ts`（卡片指标 / 体检清单 / 页签 / 左栏形态的配置表，按环节取值）                                                                                                  |
| 前端接口层   | `../../../web/src/api/pipeline.ts`                                                                                                                                                                            |
| 后端         | `KnowledgeFileStructureController`（组装触发 / 组装详情）、`KnowledgeFileStageController`（各环节共用的产物内容）、`StructureTaskRunner`（执行器）                                                            |
| 涉及接口     | `POST /file-results/{id}/structure`、`GET /file-results/{id}/structure-detail`、`GET /file-results/{id}/stage-content?stage=STRUCTURE`                                                                        |

卡片与抽屉是**各环节共用**的一套结构（`ChainNode` + `StageDetailDrawer`），差异全部由 `../../../web/src/types/pipeline-stage-view.ts` 的环节配置给出；链图的画布、触发弹窗、图例与轮询属执行链壳（页面索引 04-0，待梳理）。抽屉的四个固定分区、分隔条、底部下载、`stage-content` 的分页参数与解析环节共用同一套实现，本目录不复述，见 `../解析环节/01-页面功能.md` 与 `../解析环节/02-接口交互.md`。

## 待定项

- **章节层数的两种来源**：产物里有 `SECTION` 节点时按章节节点数计，没有时按一级标题数计；同一个数字在两类文档上含义不同，是否统一尚未决定。
- **「重复噪声」那一行显示哪个数**：体检清单当前显示「N 段 · M 页」，页数取噪声页数；重复页数是否该单列一行、或与噪声页数合并，尚未决定。
- **「阅读顺序」用无坐标元素数表达**：产物里没有「是否重排」的字段，当前用无坐标元素数推断，属推断口径；是否在产物里补明确的顺序标记尚未决定。
- **表格类元素的溯源取自单元格**：产物里 `TABLE` 自身不带 `provenance`（单元格带），溯源统计已改为"自身或单元格带定位即视为可回溯"，表格不再被计为缺失；是否在解析侧给表格本身补一条定位（属解析器改动）尚未决定。
- **疑似续表按疑似计数展示**：卡片与体检清单的"疑似"值取 `suspectedContinuationCount`（关系 `detail` 标「疑似」的放宽规则命中数），说明里给全部 `continuationCount`；结论文案的"疑似续表 N 处"同源。
- **预留字段的启用时机未定**：`assets`（二进制资源引用）、`orderCuts`（顺序切分数）、`candidateOrder`（候选顺序）、`headerRepeated`（页眉重复标记）、`rotation`（页面旋转）、`bboxes`（跨页分段框）都已在契约注释里标注为预留未实现或无消费方，启用时机随对应能力接入。
- **组装报告不外发**：`AssembleReport` 只服务管线内判定与日志（不落产物、不落子步骤记录），详情页统计由产物现算；是否把关键计数并入产物质量区尚未决定。
- **产物行的能力快照列语义**：组装环节没有独立能力快照，`kb_pipeline_product.capability_snapshot` 只承载产物 schemaVersion；是否统一为"阶段策略快照"语义尚未决定。
- **标记分布未验**：`marks`（`REPEATED_SEGMENT` / `REPEATED_PAGE` / `NOISE_PAGE`）在代表性 PDF 样本上的分布尚未核对；跨页续表关系的 `#p页码` 后缀已改为合并前取号，不再出现空值页号。
- **Excel 区域高亮粒度**：解析预览与组装文档里的表格都按单元格渲染，是否要按合并跨度画整块 / 整表框尚未决定。
- **合并单元格的渲染**：产物单元格只有 `row` / `col` / `text` / `isHeader`，没有合并跨度，组装文档里的合并单元格按单格铺开；是否补跨度字段（属产物契约改动）尚未决定。
- **多路来源的触发与裁决口径未定**：OCR / 版面 / 表格等路的**触发规则**归解析环节（有文字层覆盖 → 用原生；无文字层或质量信号坏 → 该页或区域走 OCR），**重叠区域的裁决规则**归组装环节（按证据裁决，来源类型只作平手裁决）。业界没有公开的来源优先级表，当前 `SOURCE_PRIORITY` 只是临时顺序。
- **解析环节同款失败文案写法**：已收口 —— 失败文案统一走 `TaskRunnerSupport.failureText`（解析与组装两个执行器共用），无消息的异常退化为异常类名，`error_msg` 不再落字面量 `null`。
- **重复判定的集合缓存容量**：按需重建的 bigram 集合缓存条数上限取 `knowledge.structure.repeat-set-cache-size`（默认 64），是否需要按文档规模自适应尚未决定；判定结果与缓存容量无关。
- **噪声页清单的呈现方式**：产物告警当前是"计数 + 最多 3 条样例"，完整清单只进日志；是否改成结构化字段（前端逐条渲染、可点击跳到该页）尚未决定。
