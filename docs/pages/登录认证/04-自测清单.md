# 自测清单

改完本页（页面、接口、后端逻辑任一）后手工过一遍。前置条件：

- 中间件已起（MySQL / Redis，见 `../../../docker/README.md`）；
- 数据库初始化脚本已执行：`../../../workbuddy-biz/src/main/resources/sql/init.sql`；
- 前端 dev server 与后端已启动。

## 注册

- [ ] 新用户名注册 → 提示「注册成功，请登录」，自动翻回登录卡并回填用户名、密码清空
- [ ] 用同一用户名再注册 → `40102`（用户名已存在）
- [ ] 用户名 2 位 / 33 位、密码 7 位 → `40001`，提示形如 `username 用户名长度须为 3-32 位`
- [ ] 邮箱留空、手机号留空 → 能注册成功（两个字段不上送）

## 登录

- [ ] 正确凭据 → 提示「登录成功」并进入 `/home`
- [ ] 密码错 → `40103`；不存在的用户名 → 同样是 `40103`（两者提示一致，不暴露账号是否存在）
- [ ] 停用账号（`kb_user.status = 0`）→ 仍是 `40103`
- [ ] 从受保护页面被踢出后登录 → 回到被中断的那个页面（`redirect` 生效）
- [ ] 手改 URL 的 `redirect` 为站外地址或 `/login` → 登录后落 `/home`（站内校验生效）

## 记住我

- [ ] 勾选后登录 → 令牌在 localStorage、`exp` 约为 30 天后
- [ ] 不勾选登录 → 令牌在 sessionStorage、`exp` 约为 1 天后；关掉浏览器再打开会话即失效
- [ ] 切换档位再登录 → 另一档里的同名键被清掉，不会两处残留

## 令牌过期与刷新

- [ ] 手改存储里的令牌（或等短期档到期）后刷新 → 被送回 `/login`，**不会卡在报错页**
- [ ] 登录后刷新页面 → 顶栏仍显示真实姓名、菜单仍按角色渲染（用户快照恢复了用户名与角色）

自测项在 `../个人中心/04-自测清单.md`（改密是个人中心页里的一块）。

## 限流与失败防护

- [ ] 同一 IP 连续第 21 次请求 `/auth/login` → `40201`（若没拦住：检查运行期类路径里是否缺 `aspectjweaver`，切面会静默失效）
- [ ] 连错 5 次密码 → 第 6 次（含正确密码）返回 `40111`
- [ ] 锁定期间观察后端日志：**没有查库、没有 BCrypt 比对**（锁定判定在第一步）
- [ ] 换一个用户名、同一 IP 继续错 → 仍是 `40103`（IP 维度未达 20，账号维度各自独立）
- [ ] 成功登录一次 → 该「账号 + IP」的计数清零；IP 维度**不清零**
- [ ] 等 `lock-minutes`（默认 15 分钟）后再登录 → 恢复正常
- [ ] `redis-cli --scan --pattern 'knowledge:*'` → 能看到限流桶键与失败计数键

## 非功能

- [ ] 系统开启「减少动态效果」→ 切卡不做翻转动画，直接落位
- [ ] 视口高度小于舞台高度 → 页面可滚动、顶部不被裁掉；注册卡字段增多也不撑高卡片
- [ ] Tab 键在登录卡上不会跳到背面的注册表单
