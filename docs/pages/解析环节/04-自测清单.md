# 自测清单

改完本环节（页面、接口、后端逻辑任一）后手工过一遍。前置条件：中间件已起、后端与前端 dev server 已启动，并准备一个普通用户账号与一个管理员账号、两份知识库（分别属于两人）、一份带文本层的 PDF、一份 DOCX、一份 XLSX。

## 卡片四态

- [ ] 未跑过解析的文件：卡片显示「解析」节点，指标行与摘要行是 `—`，构成图不出条
- [ ] 点「触发下一环节」→ 新节点**立即**出现且状态为「排队中」（不需要手动刷新）
- [ ] 运行中：状态点为运行色，时间显示**开始时间**，悬停给完整起止（带秒）
- [ ] 成功后：状态点成功色，时间显示结束时间，摘要行给出结论（无异常 / N 单元未解析出内容（第 a–b））
- [ ] 失败：卡片左侧出现红条，卡片上**不显示**错误原因；点「详情」在失败条里能看到错误码与建议动作
- [ ] 四种状态下卡片尺寸不变（320 × 214），操作行不被裁剪
- [ ] 构成图：四个类型各一条，条长与「该类元素数 / 元素总数」成正比；某类为 0 时**不出条**；占比很小（如 7 / 512）至少能看到 3px

## 触发与分叉

- [ ] 任务运行中再次点「触发下一环节」→ `40431`，提示里带 taskId 与当前状态
- [ ] 成功后再次点 → 仍是 `40431`（解析的执行键就是文件结果本身，成功后不会出现第二条解析运行）
- [ ] 失败后再次点 → 仍是 `40431`（失败即终局，原地重跑不可用）
- [ ] 从提交记录**重新提交同一份文件** → 产生新的 `file_result`，新链路上可以再次触发解析（`wb_source_file` 复用）
- [ ] 本节点无产物时按钮**置灰但仍在**，悬停给出原因（任务完成后可用 / 本次运行没有产物）
- [ ] 点第二张卡片触发下游 → 下游基于**被点的那张卡**的产物（分叉），不是最新一次

## 抽屉七块

- [ ] 头部：文件名、状态徽标、开始时间、耗时、任务 ID 都有值；**没有「第 N 次执行」**
- [ ] 统计条：结论一句话 + 八项统计；无任务/无产物时各项显示 `—`，**不显示「无异常」**
- [ ] 告警：无告警时该页签给空态（不是空白块）
- [ ] 失败态：错误码 + 失败说明 + 建议动作三段都在（建议动作按错误码给出下一步）
- [ ] 过程页签：失败步骤带红条与错误文案；无记录时给空态
- [ ] 元素页签：每条显示类型徽标、序号、页码、来源、表格行列；文本默认两行，点「展开」放开
- [ ] 底部：两个按钮常驻；「复制全部文本」复制当前页文本并给出条数提示

## 四个固定分区与滚动

- [ ] 抽屉高度锁在视口内，**外层不出现整页滚动条**
- [ ] 只有左栏画布区与右栏页签内容各自出现滚动条
- [ ] 左栏工具条、右栏页签条在滚动时不跟着走
- [ ] 切页签不改变左栏位置、页码与选中状态

## 原文预览与联动

- [ ] PDF：按页渲染；滚动到第 2、3 页时才渲染（大文档不要一次画完）
- [ ] 右栏点某条带坐标的元素 → 左栏跳到该页并把高亮框套在该元素上（框与内容对齐）
- [ ] 左栏点原文 → 命中的元素在右栏滚到可见并选中；点空白处清除点选
- [ ] 左栏翻页 → 右栏切到该页元素（「只列预览当前页」开启时）；关掉开关 → 右栏看全量
- [ ] 告警里的「第 N 页」可点 → 左右两栏同跳该页
- [ ] DOCX：文档渲染出来，标题样式生效；点右栏段落 → 对应段落底色高亮
- [ ] XLSX：网格与数字正确；工作表页签可切换；点右栏单元格 → 切到对应 Sheet 且该格高亮
- [ ] `.doc` / `.xls`：左栏显示「该类型暂不支持内嵌预览」+ 文件信息，**右栏解析结果照常可看**
- [ ] 解析失败的文件：失败条出现，但左栏**照常渲染原文件**
- [ ] 「适应宽度」开启后拖动分隔条 → 内容跟着放大；关闭回到 100%

## 分隔条

- [ ] 拖动：两栏宽度跟随，分隔条高亮，拖动中不会选中文字
- [ ] 拖到两端：左栏夹在 320px、右栏夹在 360px，**不出现横向滚动条**
- [ ] 双击：回到左栏 62%，且记录被清掉
- [ ] 聚焦后用 `←/→`：每次 24px 微调；`Home`/`End` 到两端
- [ ] 关掉抽屉再打开同一次运行：栏宽沿用；换一个文件结果打开：用默认比例

## 下载

- [ ] 点「下载原文件」→ 浏览器保存出原文件，文件名正确、内容能打开
- [ ] 源文件引用缺失时按钮置灰并说明原因
- [ ] 取文件失败（例如对象被删）→ 左栏显示后端错误信封里的 `code` 与 `msg`，**不是**笼统的「读取失败」

## 分页与过滤

- [ ] 元素超过 100 条时出现翻页，翻页后列表与页码同步
- [ ] 输入关键字 → 只过滤当前页，页面明确标注「只过滤当前页」
- [ ] 传 `docPage` 后 `total` 变成该页条数（可与不传时对比）

## 归属校验

- [ ] 用 A 账号登录，直接请求 B 账号文件结果的 `parse-detail` / `stage-content` / `lineage` → **40401**，界面表现为打不开而不是 500
- [ ] 用管理员账号打开 B 账号的文件结果 → **正常可访问**（管理员放行）
- [ ] 未登录直接调这几个接口 → **40101**
- [ ] 用一个不存在的 `fileResultId` → 仍按原语义返回（记录不存在不等于越权）
