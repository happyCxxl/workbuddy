# 01 页面功能

## 给谁用

登录用户都能进。看到的范围按角色分：**普通用户只有自己创建的知识库，管理员是全部**（口径见 `README.md` 的「可见范围」章）。页头写的是「管理你的知识库」——对普通用户是字面意思。

页面回答四件事：有哪些库、每个库绑了什么策略与发布到哪个索引版本、有多少文档、从哪儿进下一步（处理链 / 索引发布 / 检索评测）。

## 页面结构

自上而下四段，高度固定（`.page` 高 = 视口 − 顶栏 − 内边距），翻页与筛选时整页不跳：

| 段     | 内容                                                                                      |
|--------|-------------------------------------------------------------------------------------------|
| 页头   | 标题「知识库」+ 一句说明 + 右侧「导入文档」                                               |
| 统计条 | 知识库 / 已启用 / 文档数（三个数**同一可见范围**，见下）                                  |
| 面板   | 顶部工具条（搜索 / 状态 / 排序 / 查询 / 清除筛选 / 刷新）+ 卡片网格 + 页脚（计数 + 分页） |
| 弹窗   | 新建/编辑知识库、导入文档（两个弹窗都在本页）                                             |

### 统计条三个数的口径

| 指标   | 取的数                                                           |
|--------|------------------------------------------------------------------|
| 知识库 | `wb_knowledge_base` 行数（含已停用）                             |
| 已启用 | 其中 `status = 1` 的行数                                         |
| 文档数 | 这些库下的 `wb_file_result` 行数（= 已建档文档数，不是提交次数） |

三个数都与列表**同一范围**：普通用户只数自己创建的库，管理员数全部。文档数按"可见库 ID 集合"再数一次结果表。

## 卡片

一张卡 = 一个知识库，从上到下：

| 区域   | 内容                                                                                           |
|--------|------------------------------------------------------------------------------------------------|
| 标题行 | 立方体图标 + 库名（**唯一可缩的一项**；长度上限保证整行显示，见下）+ 状态标签（已启用/已停用） |
| 说明   | 业务场景说明；为空时显示「暂无业务场景说明」而不是留一片空白                                   |
| 指标行 | 文档数 / 索引版本（未发布显示「未发布」并弱化）/ 最近更新时间（`HH:mm`）                       |
| 策略行 | 预处理 → 切片 → 向量化三行摘要；无绑定时按开关状态显示「未绑定」或「开关已关闭」               |
| 操作行 | 导入文档 · 编辑 · 索引与发布 · 评测 · 停用/启用 · 删除，右端是日期（`yyyy-MM-dd`）             |

**点卡片本体**（或回车/空格）进入该库的切片阶段页；操作行的按钮都做了阻止冒泡，不会连带跳转。

**各行的收缩规则**（一张卡里谁让位、谁不许被压缩）：flex 的收缩量按子项宽度**比例分摊**，「已启用」这类标签会被折成两行（实测「已启 / 用」）。每行都显式分工：

| 行     | 弹性项（承担收缩）                                   | 固定项（`flex: none`，完整显示）                 |
|--------|------------------------------------------------------|--------------------------------------------------|
| 标题行 | 库名（`min-width: 0`；上限保证显示得下，真超了换行） | 立方体图标、「默认」标记、状态标签（另加不换行） |
| 指标行 | 三个格子等宽（`flex: 1` + `min-width: 0`）           | ——（格内值超长时走省略号，而不是撑破行）         |
| 策略行 | 策略串（`flex: 1` + `min-width: 0` + 省略号）        | 行首标签（定宽 52px）                            |
| 操作行 | ——（列宽下限 380px 保证放得下）                      | 六个按钮与右端日期，整行不换行                   |

`min-width: 0` 出现在每一条弹性项上不是重复：flex 项的自动最小宽度等于 min-content，而这里的文本都是 `nowrap`（min-content = 整串宽度），不归零就压不下去，溢出会转嫁给同行的固定项 —— 上面那张卡就是这样被挤坏的。

操作行按库的状态增减：

- **已停用**：操作行显示「启用」，其余入口不变。
- 六个入口在 380px 列宽下刚好放得下；再加就要考虑收进「更多」菜单。

## 工具条

| 控件     | 行为                                                                                                                                                               |
|----------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 搜索框   | 按名称模糊查询；回车或清空即查（清空也会触发查询，避免"清空了还停在筛选结果里"）                                                                                   |
| 状态芯片 | **已启用（默认）/ 已停用**，点击即查。只有两态、没有「全部」：列表是日常管理入口，停用的库不参与接入与检索，混在默认视图里只会占满常用的一屏；要看停用的切一下即可 |
| 排序     | 默认（按新建倒序）/ 最近更新 / 名称                                                                                                                                |
| 查询     | 手动触发（改完关键字不想等回车时用）                                                                                                                               |
| 清除筛选 | 关键字清空、状态回到默认的「已启用」、排序回默认，再查一次                                                                                                         |
| 刷新     | 重新拉列表与统计；加载中禁用并旋转图标                                                                                                                             |

工具条**不重复显示总数**：计数只在页脚说一次。

## 分页

- **每页固定 12 条**，不做条数选择器：12 是网格的整除值 —— 2 列 6 行、3 列 4 行、4 列 3 行，末行都不留半排空位（10 在这三种列数下都会留）。而且面板高度固定、网格内部滚动，"每页多少条"并不改变可见区域，选择器没有信息量。口径与首页「每页固定 10 条」一致。
- 分页只有上一页/当前页/下一页（不列全部页码，左右各一格箭头）；切换筛选会回到第 1 页，避免停在越界页码。
- 删除当前页最后一条时自动回退一页。

## 新建 / 编辑弹窗

| 字段         | 说明                                                                                                                           |
|--------------|--------------------------------------------------------------------------------------------------------------------------------|
| 知识库名称   | 必填，≤14 字符；输入框带 `maxlength` 与字数计数器（**上限按显示宽度倒推，保证整行显示**，见下方"两个上限怎么定的"）            |
| 业务场景说明 | ≤64 字符；输入框带 `maxlength` 与字数计数器（见下方"两个上限怎么定的"）                                                        |
| 策略绑定     | 单选：绑定（触发走本库绑定策略）/ 不绑定（测评模式，触发须显式选策略）                                                         |
| 三件套选择器 | 预处理 / 切片 / 向量化各一个下拉，只列**启用中**的版本；按开关禁用而不是隐藏（隐藏会让弹窗高度跳动，用户也看不到有哪些项要选） |

**两个上限怎么定的（名称 14 / 说明 64）**：都按"它最终要显示在哪、能显示多少"倒推，而不是随手给个大数。

- **名称 14**：显示在卡片标题行。列宽下限 380px 的卡片内宽 344px，扣掉立方体图标（38px）、两个 11px 间距与状态标签（约 68px）后**留给库名约 216px**；库名 15px 字、汉字全宽即 15px/字 → **216 ÷ 15 = 14 字**。数字与字母比汉字窄，14 字以内**必然整行显示完整** —— 上限就是这么倒推出来的。
- **说明 64**：显示在卡片正文（12px 字，约 28 字/行），64 字约 **2 行**。512 字一条写满要占十几行，会把整行卡片撑成"高个子"、连带同行的虚线卡一起变高。
- 两者还得有层级：**名称是标签，说明才是描述**，名称（14）短于说明（64）。
- **口径是"从长度上保证显示完整"，不是"允许超长、再用省略号与悬停提示兜"**：名称不做省略号截断，卡片也不再靠悬停提示露出全名；真到了超出的一天（字体渲染比估算宽），兜底是**换行成两行**而不是截断。上限落在两处 —— 输入框 `maxlength`（硬拦）+ 表单规则（兜底，覆盖粘贴等路径），数值取自 `web/src/types/knowledge-base.ts` 的 `KB_NAME_MAX` / `KB_DESCRIPTION_MAX`，与后端 DTO 的 `@Size` 同口径。

两条交互约定：

- **「开关开着但还没绑」是允许的中间态**：建库时先决定要不要绑定，具体绑哪个版本要等评测出结果，三件套齐全性只在**保存时**校验，缺哪项就在提示里点名。
- 保存是两步：先落基础字段与开关，开关为「绑定」时再提交整套绑定（后端要求一次给全三件套，少一项报 `40001`）。
- 编辑时先填列表快照再拉一次详情回填 —— 列表快照可能已被他人改动，直接用它会用陈旧值覆盖别人的修改。

## 导入文档弹窗

从页头进入不预选知识库，从卡片进入预选该库。流程是「上传到文件中心拿 fileId → 提交到知识库建档」，多文件逐个处理并显示各自状态（待导入 / 上传中 / 建档中 / 已导入 / 失败）。**只建档、不建任务**：完成后提示"到执行链页逐个环节手动触发"。候选库一次拉 500 条并在前端搜索；已停用的库标灰禁选 —— 后端会在提交时拒（`40421`），标灰标明该库不可选。

## 加载与空态

- **加载不卸载列表**：刷新与筛选时网格保持原位，用覆盖层表示加载中。整块替换成「加载中…」会让卡片与新建虚线卡一起消失、滚动位置丢失、容器内容跳动。
- **空态有两种文案**，靠"有没有偏离默认视图"区分：偏离（有关键字，或切到了「已停用」）→ 「没有符合当前筛选条件的知识库」+「清除筛选」按钮；没偏离 → 「还没有启用的知识库」，并提示"已停用的库切到「已停用」查看"。
- **状态是二选一**：进页面固定落在「已启用」，页脚的「共 N 个」就是启用的库数；停用/启用一个库后它会立刻移出当前视图，提示语点明这一点（「已停用，已移出「已启用」列表」）。
- 新建入口是网格里的**虚线卡，固定在第一位**：满页时不会被挤到滚动区底部。
- **虚线卡与知识库卡永远等高**：网格行高有定值下限（`minmax(340px, auto)`）。这一点必须靠行高而不是虚线卡自己的 `min-height` —— 网格项默认 stretch，同一行的两张卡会互相拉平，但**列表为空时那一行只有虚线卡**，没有参照物，卡片回到自身内容高度。行高用 `minmax` 而非定值：业务场景说明写得长时卡片会更高，行跟着长，同一行的虚线卡一起长。
- 网格行高有下限后，空态不再与网格平分面板高度（`flex: none`，只占自身高度）。

## 停用 / 启用的语义

停用不是"隐藏"，而是**中止服务**：该库随后拒绝新文件接入与检索（后端 `KnowledgeBaseRules.checkCanSubmit` → `40421`），已发布的索引与历史数据都还在，可以随时重新启用。确认框把后果写出来（"停用后将拒绝新文件接入与检索"），而不是只问一句"确认停用？"。

删除是逻辑删除且**无恢复接口**，确认文案里也写明了这一点。
