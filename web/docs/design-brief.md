# 前端设计需求 Brief

> 状态：主色已选定（翡翠，见 §3）；登录页待定稿，全局框架待出稿
> 对应产品：工作台 —— 企业知识库管理与检索评测平台

## 1. 产品与背景

面向知识工程师、算法与评测人员的企业内部工具：文档上传、向量库与索引管理、检索评测、指标对比是核心场景。专业工具属性要求信息清晰、操作高效；视觉上用户明确要求**极致的酷炫与优雅**。

## 2. 总体风格目标

一句话：**深空科技感与高级简约的平衡——像 Linear/Raycast 那样酷，像 Apple 那样优雅。**

- 酷炫：深色底、玻璃拟态、渐变辉光、星云质感、克制的霓虹点缀、流畅动效
- 优雅：大量留白、精细排版、严格对齐、柔和圆角与阴影、动效宁缺毋滥
- 色彩克制：主色 + 强调色，全站色相不超过三种，饱和度收敛

## 3. 视觉语言

### 色彩（深色优先，当前不做浅色主题）

| 用途     | 建议                                                                               |
|----------|------------------------------------------------------------------------------------|
| 背景层级 | 深空蓝黑，`#0A0E17`（页面底）到 `#0D1220`（面板底）逐层提亮                        |
| 表面     | 玻璃卡片：白 2–6% 半透明 + 1px 半透明描边 + 背景模糊                               |
| 主强调色 | 已选定：翡翠渐变 `#34D399` 至 `#2DD4BF`                                            |
| 语义色   | 暗底高亮版：成功 `#A3E635`（青柠，避免与主色撞色）、警告 `#FBBF24`、危险 `#F87171` |
| 文字     | 主 `#E6EAF2`、次 65% 透明度、弱 38% 透明度                                         |
| 氛围光   | 极光式低饱和大面积渐变（紫到青），用于登录页背景与页面头部                         |

### 字体

- 中文：系统无衬线（PingFang SC / Microsoft YaHei / Segoe UI）
- 数字与指标：等宽（tabular-nums / JetBrains Mono），强调数据感
- 标题字重偏细、行距宽松，营造高级感

### 形状与间距

- 圆角分层：8 / 12 / 16px（卡片 12，弹层 16）
- 间距以 4/8 为基数，卡片与区块之间留白充足
- 阴影柔和、低扩散；描边比阴影更常用（玻璃感）

## 4. 动效与质感

- 入场：页面渐显 + 上浮 6–10px，200–300ms ease-out
- 交互：hover 辉光/描边亮起、按钮按压回弹、输入聚焦辉光
- 背景：极光呼吸、星点漂移，仅用 transform/opacity 实现，保证流畅
- 原则：全部动效支持 reduced-motion 降级；禁止扫光、弹跳、持续闪烁等廉价效果

## 5. 设计范围

1. **登录页**：品牌展示 + 登录表单，是风格的第一印象载体
2. **全局框架**：侧边导航 + 顶栏 + 内容区的整体风格定调，后续知识库、索引、评测等页面按此套用

## 6. 技术还原约束（Element Plus 落地）

- 以 Element Plus 组件体系（el-form / el-button / el-table / el-menu 等）为基础，通过其 dark theme CSS 变量 + 自定义 `--el-color-primary` 等实现品牌色
- 玻璃拟态、渐变辉光由 scoped CSS 与 `styles/` 下设计变量实现，不引重型动画库
- 设计稿须交付：页面 HTML + 设计 token 清单（颜色、圆角、阴影、动效参数），以便精确还原

## 7. 硬性合规约束

- 纯中文界面（可保留 ID、JSON 等业界通用缩写）
- 禁止出现"家庭/home""shangjige"字样，无租户概念，品牌名为「工作台」（副标题「AI 工作台」）
- 落地代码须过前端 lint 门禁（静态检查引擎口径见 `.agent/standards/frontend/03-异步与测试.md` §4）

## 8. 参考方向

- 酷炫侧：Linear（深色渐变微光）、Raycast（玻璃 + 霓虹点缀）、Vercel（留白 + 渐变字）
- 优雅侧：Apple 官网（排版与克制动效）、Arc（细腻玻璃质感）
- 背景氛围：星云/极光色调（类似 Apple 屏保的暗底渐变）

## 9. 反模式清单

- ❌ 五颜六色、主色系之外的颜色泛滥
- ❌ 廉价霓虹（高饱和荧光绿/品红大面积使用）
- ❌ 过度动效：全页扫光、弹跳、持续闪烁
- ❌ 花哨 3D 或重粒子系统抢戏、拖慢性能
- ❌ 赛博朋克廉价感（扫描线、故障风）

## 10. 验收标准

1. 登录页先出 2–3 个风格方向，选定 1 个后深化定稿
2. 全局框架风格稿 1 套
3. 交付设计 tokens + 可复用样式清单
4. 落地 Vue 代码通过全部门禁，视觉还原度由用户主观验收（目标 ≥90%）
